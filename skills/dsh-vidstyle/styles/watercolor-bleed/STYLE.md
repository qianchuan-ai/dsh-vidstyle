# 水彩晕染 — watercolor-bleed

> 湿纸上的透明水彩，颜色自己往纤维里跑，水痕在边缘堆出深色的一圈。本风格做的是
> **「水的不可控」**——你画一笔，水替你决定它长成什么样。
> 参考（只取语法）：湿画法的**颜色自走**与**水痕边缘**；干画法的**硬边叠层**；
> 留白的**纸的白**。不搬具体画作与签名，成片里不点名。

## 1. 本质，以及它不是什么

1. **水自己走**。湿画法里，颜色落在湿纸上会**自己向四周洇**，边界是**水决定的**，
   不是笔决定的——这是水彩最核心的特征。
2. **水痕**。水推开颜料，在**边缘堆出一圈更深的颜色**（backrun），这个「水痕圈」
   是水彩的签名，AI 最容易做错（常画成均匀的边）。
3. **透明叠层**。水彩是**透明的**，第二层能透见第一层，两色相叠产生**第三色**
   （蓝 + 黄 = 绿，但更透）。
4. **纸的白就是白**。高光与最亮处是**留白的纸**，不是白色颜料——水彩没有白颜料。
5. **纸纹**。粗纹水彩纸的**颗粒感**透上来，颜色在颗粒的凹处深、凸处浅。

**不是什么**：不是油画（没有厚度与笔触的脊），不是水墨（水墨是墨的五色，水彩有彩色
且边界更水），不是数字喷绘（边界太干净），不是 3D 渲染，不是马克笔（马克笔的边界是
溶剂的，更硬）。

## 2. 材质与质感

**基底**：粗纹水彩纸。**颗粒感明显**，颜色在凹处堆、凸处浅。

**材质**：
- 钴蓝 #3A6EA5、群青 #4A5FA8 —— 冷色区，透明
- 镉黄 #E8A317、那不勒斯黄 #E8D5A0 —— 暖色区，透明
- 玫瑰红 #C0506A —— 点缀，透明
- 生褐 #8B7355 —— 中性，透明
- 纸的白 #F7F3EA —— **唯一的白**，是留白不是颜料
- 水痕边 #2A4A7A —— 边缘堆出的深色圈

**渲染逻辑**：**水带走颜料**。湿处颜色自走、边界软；干处边界硬。
水痕是**边缘的一圈深**（水把颜料推到边上）。第二层透见第一层。
AI 生成对应「软边自走 + 边缘水痕圈 + 透明叠层 + 纸纹颗粒」，不要「均匀渐变 + 硬边」。

**必须锚在世界上的**：水痕的圈、纸纹的颗粒、颜色的自走边界。**活在画面空间里的**：
整体的透明感与纸白。

## 3. 色彩逻辑

**规则**：
- **透明为主**。所有颜色是**透明的**，能透见纸与底下的层。
- **留白即白**。最亮处是纸的白，**不画白**。
- **水痕是特征**。每个色块的边缘允许有水痕圈，这是质感的来源。
- **不上的色**：不透明的覆盖色、纯白颜料、纯黑 #000（最深是深蓝加深红的调和）。
- **明度排序**：纸白（最亮）→ 单层淡色 → 叠层 → 水痕边（最暗，圈状）。

**示例色板（仅示例）**：
`#F7F3EA 纸白 / #E8D5A0 那不勒斯黄 / #3A6EA5 钴蓝 / #C0506A 玫瑰红 / #8B7355 生褐 / #2A4A7A 水痕深`

## 4. 字体与字幕

- **标题**：**手写体或细衬线**，像用细笔写在纸上，边缘可有水的毛边。
  字色用生褐 #8B7355 或深蓝 #2A4A7A。
- **字幕**：细衬线，落在纸白处，不加底条。
- **字号**：标题占画面高度 8%–11%，字幕 4%。
- **归属**：字幕像**画边的铅笔标注**，小、偏、不抢。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**不抽帧**，连续平滑——水的流动需要连贯。
- **缓动**：**水的洇开走 ease-in**（开始慢、越走越快，直到纸吃饱）；
  笔触走 ease-out（起笔快、收笔慢）。
- **重量**：水**有重量**（往下流），颜料随水走。
- **抖动**：纸不动，水在动；偶尔一滴水落下打破平静。
- **出现与消失**：颜色**从落点向四周洇开**，不是淡入；消失时被水冲淡或被新色覆盖。
- **什么永不动**：纸纹、留白。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 沿水流方向的缓慢移动 | 流淌、时间、一段过程 | 一次过程；一段旅程；颜色的流动 |
| 缓慢推近至水痕边缘 | 发现、细看、水的痕迹 | 一个细节；水的机制展示 |
| 缓慢拉远到全幅 | 全貌、完成、看清 | 一幅画的完成；一个结论 |
| 锁死画框 | 静物的凝视、纸的呼吸 | 一段静默；让观众自己看 |
| 垂直下移（从上到下） | 下落、沉淀、时间 | 一次下落；一段沉淀 |

**取景规则**：色块常压一角，留白占 40%–60%；水痕边是视觉的引导线。
**允许的转场**：水洇开遮挡、一滴水落下、颜色冲淡。
**禁止**：快速甩镜、360° 环绕、硬切到不同色温。

## 7. 声音色板

- **乐器**：钢琴的高音单音、竖琴的泛音、长笛的长音——**轻、透**，不要低音铺底。
- **拟音**：水滴落纸、水在纸上洇开的极轻声、笔洗的水声、纸被掀起。
- **环境**：极静，几乎只有水声与空气。
- **静默**：**至少三处**——留白与水需要静默。
- **混音**：音乐极轻，水声是主角之一；响度 −14 LUFS。
- **人声**：轻，慢，像耳语。

## 8. 招牌动作

- **一滴水落下。** 一滴清水落在已有的颜色上，**把颜料推开**，形成一个水痕圈。
  *适合内容如：*一次扰动；一个变化的开始；一次意外。

- **两色相撞。** 两种颜色在湿纸上**相遇**，交界处自己混出第三色。
  *适合内容如：*一次融合；两个概念的结合；一次对比后的综合。

- **水痕蔓延。** 水痕的边缘**缓慢向外蔓延**，越走越慢，直到纸吃饱。
  *适合内容如：*时间的推移；一次扩散；影响的蔓延。

- **留白显形。** 留白胶撕掉，**纸的白显出来**，形状一下子亮了。
  *适合内容如：*一次揭晓；一个高光；一个结论的清晰化。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **水痕变均匀边** | 边缘变成均匀的深色描边 | 写「边缘水痕圈深浅不均，是水推开颜料堆的，非均匀描边」 |
| **边界太干净** | 变成数字喷绘 | 「湿处边界软且自走，干处边界硬，两种并存」 |
| **变成不透明** | 颜料覆盖了底下的层 | 「透明叠层，第二层透见第一层，交界混出第三色」 |
| **用了白颜料** | 高光是画上去的白 | 「最亮处是留白的纸，不画白」 |
| **退化成 3D** | 变成 3D 渲染 | 负面词必须有「不要 3D 渲染质感、不要立体塑形」 |
| **纸纹没了** | 变成平滑 | 「粗纹水彩纸颗粒透出，颜色凹处深凸处浅」 |

**该风格的默认退化项（负面词必备）**：
`不要不透明覆盖，不要白颜料，不要均匀渐变，不要 3D 渲染质感，不要照片级锐度，不要硬边描线，不要纯黑纯白`

## 10. 提示词配方

### 一句话版

```
透明水彩湿画法，颜色自走洇开，边缘有水痕圈，第二层透见第一层，粗纹纸颗粒透出，留白即白，非厚涂非3D。
```

### 完整版

```
{风格锚点}：透明水彩，湿画法。
{材质与色彩}：颜色湿润处自走洇开（边界软，非笔决定），干处边界硬，两种并存；
边缘有水痕圈 #2A4A7A（深浅不均，是水推开颜料堆的，非均匀描边）；透明叠层，第二层透见第一层，
交界混出第三色；最亮处是留白的纸 #F7F3EA，不画白；粗纹纸颗粒透出（凹处深凸处浅）。
{主体与环境}：{主体}，{环境}，色块压画面一角，留白占一半。
{光照}：无体积光，明度由纸白到水痕深分层，透明感。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，颜色自走洇开（ease-in，越走越快直到纸吃饱），纸与留白静止，连续平滑。
负面：不要不透明覆盖，不要白颜料，不要均匀渐变，不要 3D 渲染质感，不要照片级锐度，不要硬边描线，不要纯黑纯白。
```

**占位符填法**：
- `{主体}` → 「一座远山」「一片花瓣」「一个模糊的人影」——**水彩适合不精确的形**
- `{环境}` → 「周围是纸的白」为主；需要时加「下方一抹淡蓝的水」
- `{运镜}` → 缓慢推近至水痕边缘，最能看到水彩的机制

**最容易错**：边界写成硬边；用了白颜料；颜色不透明；水痕写成均匀描边。

## 11. 变化空间

**三个结构**
1. **一滴成画**：一滴水落下，推开颜料，洇出一个形状，逐层叠成一幅画。
2. **两色相遇**：两种颜色从画面两侧流向中间，相遇混出第三色。
3. **由淡及浓**：从最淡的一层开始，逐层叠到最深，最后水痕显现。

**三个开场**
1. 全是纸白，一滴水落下。
2. 水痕边缘的极特写，水在缓慢蔓延。
3. 两滴不同的颜色各自洇开，即将相遇。

**三个结尾**
1. 水痕蔓延到画面边缘，停住，留白扩大。
2. 镜头拉远，一幅画缩成纸上一角。
3. 一滴清水落下，把最深的颜色冲淡，收在纸白上。
