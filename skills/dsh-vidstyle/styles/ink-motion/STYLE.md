# 水墨动画 — ink-motion

> 生宣上的湿墨，边缘有纤维毛刺，墨分五色由焦到清。本风格做的是**墨在纸上洇开的那一下**——
> 不是画好的画，是正在发生的画。
> 参考（只取语法）：中国水墨动画的**墨色渗化**与**留白即空间**；写意花鸟的**笔势与飞白**。
> 不搬具体片目、构图与题款，成片里不点名。

## 1. 本质，以及它不是什么

1. **洇**。墨落在生宣上会**向纤维里渗**，边缘是毛的、不规则的，有细小的毛刺——这是水墨
   最核心的特征，也是 AI 最容易做错的地方。
2. **墨分五色**。焦、浓、重、淡、清——同一支墨的五个明度层次，**没有第二色**。
3. **留白即空间**。留白是水、是雾、是天、是路，不是没画完。
4. **笔势**。每一笔都有方向与速度的残留——飞白（笔干处的白丝）、笔锋的出入，都看得见。
5. **意在笔先**。构图先有气势再有细节，常有「不完整」的笔，故意留着。

**不是什么**：不是工笔（没有细勾线与多层罩染），不是水彩（水彩有边界与纸纹颗粒，没有
墨的五色层次），不是 3D 渲染，不是 Photoshop 的渐变工具（渐变太干净，没有毛刺）。

## 2. 材质与质感

**基底**：生宣。**未施胶矾**，所以墨一落就渗。可见纤维纹理，纸色微黄 #F5F0E6。

**墨色五档**（同一支墨的明度）：
- 焦墨 #1A1A1A —— 最浓，几乎不反光，用于点睛与最重处
- 浓墨 #2E2E2E —— 主体轮廓与实处
- 重墨 #4A4A4A —— 中间层次
- 淡墨 #8C8C8C —— 远景、次要处
- 清墨 #C8C8C8 —— 几乎是水，用于最远与最虚

**渲染逻辑**：**湿墨入纸，边缘渗化**。一笔下去，中心浓、边缘因渗化而变淡变毛，
且**渗化会继续**（在动画里就是洇开的过程）。飞白是笔干处纸纤维没吃到墨。
AI 生成对应「湿墨 + 纤维毛刺边缘 + 中心浓边缘淡」，不要「硬边色块」。

**必须锚在世界上的**：洇开的边缘、飞白的丝、纸的纤维。**活在画面空间里的**：整体的黑白灰调。

## 3. 色彩逻辑

**规则**：
- **只有五色**。焦浓重淡清，全部是墨的明度，**没有第二色**。
- **留白占 40%–70%**。留白是构图的主体。
- **最浓的墨只点几处**（点睛、最重的结构），大面积用淡墨。
- **不上的色**：任何彩色、纯黑 #000（焦墨是 #1A1A1A 不是纯黑）、纯白 #FFF（纸是 #F5F0E6）。
- **明度排序**：留白（最亮）→ 清墨 → 淡墨 → 重墨 → 浓墨 → 焦墨（最暗，点状）。

**示例色板（仅示例）**：
`#F5F0E6 生宣 / #C8C8C8 清墨 / #8C8C8C 淡墨 / #4A4A4A 重墨 / #2E2E2E 浓墨 / #1A1A1A 焦墨`

## 4. 字体与字幕

- **标题**：行草或手写体，取其**笔势**，不要印刷体的工整。字色用浓墨 #2E2E2E。
- **字幕**：细宋体或仿宋，字重偏轻，落在留白上，不加底条。
- **字号**：标题占画面高度 8%–12%，字幕 4%。
- **归属**：字幕像**画上的题款**，可以竖排，位置在留白处不压主体。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**不抽帧**，但**墨的渗化本身是分段的**——洇开是一波一波的，不是匀速。
- **缓动**：笔触走 **ease-out**（起笔快、收笔慢，像真的运笔）；墨的洇开走 **ease-in**
  （开始慢、越渗越快，直到纸吃饱）。
- **重量**：墨有重量，落下时**先重后散**。
- **抖动**：纸不动，笔在动；偶尔笔锋的轻微颤动（手绘感）。
- **出现与消失**：一切**从留白里被笔画出来**，不是淡入；消失时被墨盖住或被水冲淡。
- **什么永不动**：纸的纤维、留白。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 沿笔势方向的跟随移动 | 运笔、书写、一段生成 | 一个字/一幅画的生成；一段创作过程 |
| 极缓慢横移（手卷式） | 时间、山水、一段历程 | 山水长卷；一段旅程；并列的场景 |
| 从淡墨处推向焦墨处 | 聚焦、加重、深入 | 一个重点；一次加重；从虚到实 |
| 锁死画框 | 留白的呼吸、凝视 | 一段静默；让观众自己看 |
| 缓慢拉远（从局部到全幅） | 全貌、格局、完成 | 一幅画的完成；一个结论 |

**取景规则**：主体常压在画面一角，留白占 40%–70%；墨色最重处与留白形成对角张力。
**允许的转场**：墨滴洇开遮挡、一笔扫过画面、留白淡出。
**禁止**：硬切到不同色温、360° 环绕、快速甩镜（破坏笔势）。

## 7. 声音色板

- **乐器**：古琴、箫、琵琶的散音——**极简**，不要钢琴弦乐铺底。
- **拟音**：笔锋擦纸的沙沙、墨滴落纸的「嗒」、水在纸上洇开的极轻声、洗笔的水声。
- **环境**：极静的书房，几乎只有空气与纸的声音。
- **静默**：**至少三处近乎全静**——留白要配静默。
- **混音**：音乐极轻，闪避明显；响度 −14 LUFS。
- **人声**：慢，留白多，像吟诵。

## 8. 招牌动作

- **墨滴洇开成形。** 一滴墨落在留白上，向纤维里洇开，洇出的形状**恰好是一个东西**
  （一片叶、一座山、一个人）。
  *适合内容如：*一个开场；一个概念从无到有；一次灵感的落笔。

- **一笔扫过。** 一笔从画面一侧扫到另一侧，笔过之处**飞白与浓淡同时出现**，带出下一个场景。
  *适合内容如：*一次转场；一个流程的推进；一段内容的翻页。

- **五色渐变显影。** 同一个形状从清墨逐层加到焦墨，五色一层层叠上来。
  *适合内容如：*一个概念的逐步加深；一个人物的立体化；一段分析的展开。

- **水冲淡墨。** 一股清水冲过墨迹，把浓墨冲成淡墨，露出底下的纸。
  *适合内容如：*一次撤销、返工；一段记忆的褪色；一个结论被推翻。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **洇变成渐变** | 边缘太干净，像 Photoshop 渐变 | 写「边缘有纤维毛刺，不规则渗化，非平滑渐变」 |
| **变成工笔** | 长出细勾线与均匀填色 | 负面词必须有「不要工笔勾线、不要均匀填色」 |
| **退化成 3D** | 变成 3D 渲染的墨 | 「不要 3D 渲染质感、不要立体塑形、不要 CG 光泽」 |
| **变成水彩** | 有水彩的边界与颗粒 | 「不要水彩边界、不要纸纹颗粒堆叠」 |
| **留白没了** | 画面被墨填满 | 「留白占画面一半以上，墨色最重处只点几处」 |
| **太黑** | 大面积焦墨 | 「大面积用淡墨，焦墨只点睛」 |

**该风格的默认退化项（负面词必备）**：
`不要工笔勾线，不要均匀填色，不要水彩边界，不要 3D 渲染质感，不要照片级锐度，不要彩色，不要纯黑纯白`

## 10. 提示词配方

### 一句话版

```
生宣水墨动画，湿墨洇开边缘有纤维毛刺，墨分五色焦浓重淡清，大留白，笔势明显，非工笔非3D。
```

### 完整版

```
{风格锚点}：生宣水墨动画。
{材质与色彩}：湿墨入纸，边缘纤维毛刺不规则渗化，非平滑渐变；墨分五色——焦 #1A1A1A、
浓 #2E2E2E、重 #4A4A4A、淡 #8C8C8C、清 #C8C8C8，纸色 #F5F0E6；只有黑白灰，无第二色；
可见飞白的白丝与笔锋出入，留白占画面一半以上。
{主体与环境}：{主体}，{环境}，构图压在画面一角。
{光照}：无光源，画面自发光，明度由留白到焦墨逐层递减。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，墨色洇开一波一波（非匀速），笔触起笔快收笔慢，纸与留白静止。
负面：不要工笔勾线，不要均匀填色，不要水彩边界，不要 3D 渲染质感，不要照片级锐度，不要彩色，不要纯黑纯白。
```

**占位符填法**：
- `{主体}` → 「一座远山」「一片荷叶」「一个侧身行走的人」——**写意的、不完整的形**
- `{环境}` → 「周围大面积留白」为主；需要时加「下方一抹淡墨的水纹」
- `{运动}` → 「轮廓从淡墨逐层加到焦墨」「墨滴洇开成形」

**最容易错**：写成工笔（加了勾线）；留白填满；洇开写成「平滑渐变」；给全黑。

## 11. 变化空间

**三个结构**
1. **一笔成画**：从一笔开始，逐笔加出一幅完整的画，最后镜头拉远看全貌。
2. **由虚入实**：从清墨的虚形开始，逐层加到焦墨的实形，一个概念逐渐清晰。
3. **水冲重来**：画到一半被水冲淡，重新落笔，第二次更简练。

**三个开场**
1. 全是留白，一滴墨落下，洇开。
2. 笔锋特写，擦过纸面，飞白出现。
3. 淡墨的形在留白里若隐若现，逐渐显形。

**三个结尾**
1. 最后一笔焦墨落下，画面静止，留白扩大。
2. 镜头拉远，一幅画缩成画面一角，题款浮现。
3. 水冲过画面，墨迹淡去，只剩纸的纤维。
