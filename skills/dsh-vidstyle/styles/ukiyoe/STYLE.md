# 浮世绘 — ukiyoe

> 江户木版画：多版套印的平涂色块，木刻的钝感线条，大胆裁切的非对称构图，蓝是普鲁士蓝。
> 本风格做的是**「版的叠加」**——一版一版压上去，最后一张锦绘成立。
> 参考（只取语法）：浮世绘的**套色版次**与**钝感刻线**；葛饰北斋的**波浪与富士的尺度反差**；
> 歌川广重的**名所构图与天气**。不搬具体画作、役者脸与题字内容，成片里不点名。

## 1. 本质，以及它不是什么

1. **平涂无渐变**。每个色块是**均匀的平色**，块与块之间是硬边——除了「晕染」（bokashi），
   那是**专门做出来的**渐变，只在天空与水面用，且是**分层的带状**，不是连续渐变。
2. **木刻的钝感线**。轮廓线是**刀刻出来的**，粗细有手工的不齐，转角处略钝——
   不是毛笔的流畅，也不是矢量的锐利。
3. **多版套印**。颜色是**一版一版压上去的**，所以色块之间有**极轻微的错位**
   （约 1–2 像素），这个错位是特征不是错误。
4. **大胆裁切**。主体常被画面边缘**切掉一部分**（半只船、半只手），构图非对称、有倾斜。
5. **蓝的主导**。普鲁士蓝（bero-ai）是主色，配红花色与土黄，构成三色体系。

**不是什么**：不是工笔（线条是刻的不是描的），不是水彩（没有水的边界与纸纹），
不是 3D 渲染，不是现代插画（没有平滑渐变与厚涂），不是写实（空间是平面的）。

## 2. 材质与质感

**基底**：和纸。可见纤维，色块印上去后**透出纸纹**，颜色因此不纯净。

**材质**：
- 普鲁士蓝 #2B4C7E —— 主色，山、水、影
- 红花色 #C0392B —— 衣饰、花、点缀
- 土黄 #C9A227 —— 建筑、地面、秋
- 藤灰 #8C8C8C —— 次要处与远景
- 和纸 #EDE4D3 —— 底色，透出纤维
- 墨线 #1A1A1A —— 轮廓，刀刻的钝感

**渲染逻辑**：**一版一版平压**，每色一块，硬边，块间有 1–2 像素错位。
「晕染」是**带状分层**的（天空从上到下 3–4 层），不是连续渐变。
AI 生成对应「平涂色块 + 硬边 + 轻微套印错位 + 带状晕染」，不要「平滑渐变」。

**必须锚在世界上的**：刻线的钝感、套印的错位、纸的纤维。**活在画面空间里的**：
整体的蓝主导与低饱和。

## 3. 色彩逻辑

**规则**：
- **三色体系**。蓝、红花、土黄为主，藤灰为辅，**不超过五色**。
- **蓝压场**。蓝占画面 30%–50%，红只点在最关键处（一件衣、一朵花）。
- **晕染只带状**。天空与水面的渐变是**分层的带**，不是连续的。
- **不上的色**：连续渐变、荧光色、任何高饱和的紫与粉。
- **明度排序**：和纸（最亮）→ 土黄 → 藤灰 → 红花 → 普鲁士蓝 → 墨线（最暗）。

**示例色板（仅示例）**：
`#EDE4D3 和纸 / #C9A227 土黄 / #8C8C8C 藤灰 / #2B4C7E 普鲁士蓝 / #C0392B 红花 / #1A1A1A 墨线`

## 4. 字体与字幕

- **标题**：**楷书或江户时代的木刻字**，字形略扁，有刻的钝感。字色用墨 #1A1A1A。
- **字幕**：细宋体，落在和纸底上，可加一枚朱色的落款印（红 #C0392B 的方框）。
- **字号**：标题占画面高度 9%–12%，字幕 4%。
- **归属**：字幕像**画上的题签**，位置在画面一角（右上或左下），不压主体。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

**注意**：浮世绘原作的题字是日文。中文题字请用**简体中文**，不要伪造日文假名。

## 5. 运动质感

- **抽帧感**：**隔帧动画（on twos）**，约 12 fps——版画的拓印是一张一张的。
- **缓动**：**起步与收尾突兀，中间匀速**（拓印的停顿感），不用柔顺曲线。
- **重量**：色块**平的**，没有体积重量；动的是版次的叠加与形状的出现。
- **抖动**：**套印错位的轻微抖动**（每帧 1–2 像素），这是核心质感。
- **出现与消失**：形状**被刻出来**（线条先出现，色块后压上），不是淡入。
- **什么永不动**：和纸纤维、刻线的钝感、构图的倾斜。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 横向平移（绘卷式） | 旅程、名所、一段路程 | 一段旅行；并列的场景；四季 |
| 缓慢推近至主体 | 聚焦、欣赏、细看 | 一个细节；一次凝视 |
| 沿波浪/云的方向移动 | 自然力、动势、气势 | 一次自然现象；一段情绪 |
| 锁死画框 | 版画的「看」、构图本身 | 让观众看构图；一段静止 |
| 缓慢上移（从地面到天空） | 尺度、由近及远、仰望 | 从人到自然的尺度反差 |

**取景规则**：主体常压一角并被边缘切掉一部分；地平线**高或低**（不居中）；
蓝的区域（水/山/影）占大面积。**允许的转场**：套色版次叠加、波浪遮挡、
形状被刻出来。**禁止**：360° 环绕、快速甩镜、连续渐变转场。

## 7. 声音色板

- **乐器**：三味线、尺八、太鼓——**日本传统乐器**，不要钢琴弦乐。
- **拟音**：拓印的「嗒」、刻刀刻木、纸被掀起、水波。
- **环境**：江户的市声（远景、模糊）、风与水。
- **静默**：**至少两处**，拓印声停，只剩纸的动静。
- **混音**：太鼓给节奏，三味线给旋律，人声在上；响度 −14 LUFS。
- **人声**：慢，有叙事感，像讲浮世草子。

## 8. 招牌动作

- **套色版次叠加。** 一版一版压上去：先是墨线版，然后蓝版、红版、黄版，最后一张锦绘。
  *适合内容如：*一个产品的逐层组装；一段分析的逐层展开；一个概念的构建。

- **波浪卷起。** 巨浪从画面一侧卷起，浪尖的白是**留白的刻线**，不是白色颜料。
  *适合内容如：*一次冲击；一个转折；自然力量的展示。

- **晕染带展开。** 天空的带状晕染**一层一层展开**（3–4 层），像染布。
  *适合内容如：*时间的推移；一次情绪的变化；从白天到黑夜。

- **形状被刻出来。** 轮廓线**先出现**（刀在走），然后色块压进去。
  *适合内容如：*一个形象的诞生；一次创作过程；一个产品的轮廓显现。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **脸崩** | 浮世绘的役者脸比例特殊，AI 常画成写实脸 | 写「侧面剪影感的脸，五官简练，非写实」；避开正面特写 |
| **变成平滑渐变** | 天空变成连续渐变 | 写「带状晕染，分 3–4 层，非连续渐变」 |
| **线条太锐** | 变成矢量插画 | 「木刻的钝感线，粗细有手工不齐，转角略钝」 |
| **退化成 3D** | 变成 3D 渲染 | 负面词必须有「不要 3D 渲染质感、不要立体塑形」 |
| **套印错位没了** | 色块完美对齐，像矢量 | 「色块间有 1–2 像素的套印错位」 |
| **颜色太多** | 超过五色 | 「不超过五色，蓝为主」 |

**该风格的默认退化项（负面词必备）**：
`不要连续渐变，不要 3D 渲染质感，不要照片级锐度，不要立体塑形，不要矢量锐边，不要超过五色，不要写实脸`

**占位符填法**：
- `{主体}` → 「浪尖上的富士山」「桥上走过的人群」「雨中的行路人」
- `{环境}` → 「下方是普鲁士蓝的海面」「远处是土黄的屋脊」
- `{运镜}` → 横移最贴浮世绘的「绘卷」感

**最容易错**：天空写成连续渐变；线条太锐；颜色超过五色；正面脸特写。

## 11. 变化空间

**三个结构**
1. **名所并列**：镜头横移，依次经过三处名所，同一构图规则，蓝的比例各偏一档。
2. **套色过程**：从墨线版开始，一版一版压上色，最后一张锦绘完成。
3. **由浪及山**：从浪的特写开始，镜头上移，露出远处的富士，形成尺度反差。

**三个开场**
1. 全是和纸，墨线先被刻出来。
2. 一版蓝压上，画面从白变蓝。
3. 波浪的极特写，浪尖的留白刻线。

**三个结尾**
1. 最后一版压上，画面静止，落款印浮现。
2. 镜头拉远，画缩成一张版画贴在墙上。
3. 套色错位逐渐加大，画面「印歪」了，收在趣味上。
