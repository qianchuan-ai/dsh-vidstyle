# 像素复古 — pixel-retro

> 低分辨率网格上的有限色板，硬边无抗锯齿，渐变靠抖动（dithering）一格一格点出来。本风格做的是
> **「格子的诚实」**——放大看得见每一格，缩回去才成形。
> 参考（只取语法）：16 位机时代的**有限色板与抖动渐变**；街机的**硬边与高对比**；
> sprite 动画的**隔帧节奏**。不搬具体游戏、角色与 UI，成片里不点名。

## 1. 本质，以及它不是什么

1. **格子可见**。画面由**明确的方形像素**构成，放大看得见网格，**没有抗锯齿**——
   斜线是阶梯状的，不是平滑的。
2. **有限色板**。整个画面**不超过 32 色**（常见 16 色），每个颜色是**离散的**，
   没有连续渐变。
3. **抖动做渐变**。深浅过渡是**两种颜色交替排列**（dithering）点出来的，
   不是混合出来的——这是像素画渐变的唯一合法方式。
4. **网格对齐**。所有形状的边缘**对齐像素网格**，没有半格。
5. **隔帧动画**。动效明显抽帧（on twos 或 on threes），有游戏 sprite 的顿挫感。

**不是什么**：不是矢量（矢量是平滑的），不是低分辨率的照片（照片没有有限色板与抖动），
不是 3D 渲染，不是「模糊的复古滤镜」（像素画是**清晰的**，只是格子大）。

## 2. 材质与质感

**基底**：像素网格。**每个格子是一个纯色**，格子之间无过渡。

**材质**：
- 主色组（16 色为限）：
  - 深 #1A1A2E、中 #4A4A6A、亮 #8A8AB0 —— 暗部与中间调
  - 主 #E85D4A（红）、#5A9E4A（绿）、#3A6EA5（蓝）—— 三个主色
  - 高光 #F5E6C8 —— 最亮
- 抖动格 —— 两种颜色**交替排列**（棋盘格或 25% 密度），用于过渡
- 无渐变、无模糊、无抗锯齿

**渲染逻辑**：**格子是离散的**。形状边缘对齐网格，斜线是阶梯。
渐变用**抖动**（两种颜色的点阵交替）。放大后每个格子是纯色。
AI 生成对应「方形像素 + 硬边阶梯 + 抖动点阵 + 有限色板」，不要「平滑 + 抗锯齿」。

**必须锚在世界上的**：像素网格、抖动的点阵、硬边阶梯。**活在画面空间里的**：
整体的高对比与有限色。

## 3. 色彩逻辑

**规则**：
- **≤32 色**。超过 32 色就不是像素画了。常见 16 色。
- **抖动是唯一的渐变**。深浅过渡必须用两种颜色的点阵交替，**不许混合**。
- **高对比**。暗部很暗，亮部很亮，中间调靠抖动。
- **不上的色**：连续渐变、抗锯齿的中间色、超过色板的颜色、任何模糊。
- **明度排序**：高光（最亮）→ 亮部 → 抖动区 → 中间调 → 暗部 → 深（最暗）。

**示例色板（仅示例，16 色）**：
`#1A1A2E / #4A4A6A / #8A8AB0 / #E85D4A / #5A9E4A / #3A6EA5 / #F5E6C8 / #C9A227 / #B5485A / #2A4A7A / #6B8E5A / #E8A317 / #8B7355 / #EDE8DC / #2B2B2B / #F7F3EA`

## 4. 字体与字幕

- **标题**：**点阵字体**（pixel font），每个字母由方格拼成，**无抗锯齿**。
  字色用高光 #F5E6C8 或主色。
- **字幕**：同款点阵字体，字高至少 8 个像素（低于 8 格读不清）。
- **字号**：标题占画面高度 10%–14%，字幕 5%–6%。
- **归属**：字幕像**游戏的对话框**，在画面下缘，可有 1–2 像素的边框。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

**注意**：点阵字体在**低分辨率下**才成立。生成时要指定「低分辨率、可见像素格」，
否则 AI 会输出平滑字体。

## 5. 运动质感

- **抽帧感**：**明显抽帧（on twos 或 on threes）**，约 8–12 fps 的观感——这是核心。
- **缓动**：**台阶式**（step easing），不是平滑曲线——位移是**一格一格跳**的。
- **重量**：角色/物体**轻**，跳跃是**抛物线的像素轨迹**。
- **抖动**：**抖动格的闪烁**（两种颜色交替时的轻微闪），这是质感的一部分。
- **出现与消失**：**逐格点亮**（从一格开始向外扩展），不是淡入。
- **什么永不动**：像素网格、色板、抖动的规则。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 横向平移（卷轴式） | 通关、旅程、一段推进 | 一段旅程；关卡推进；并列的场景 |
| 缓慢推近（放大像素） | 细看、揭示格子本身 | 展示像素的本质；一个细节 |
| 缓慢拉远（缩回全貌） | 全貌、成形、看清 | 从格子到图形的成形；一个结论 |
| 锁死画框（平台视角） | 游戏的「看」、固定关卡 | 一段静止；让观众看构图 |
| 垂直上移（平台跳跃） | 上升、进步、挑战 | 一次上升；一段进步 |

**取景规则**：形状对齐网格；主体常在画面中下部（平台感）；UI 元素贴边。
**允许的转场**：像素逐格点亮、卷轴滚动、抖动区扩散。
**禁止**：平滑的缩放（必须是整数倍缩放）、抗锯齿的旋转、连续渐变转场。

## 7. 声音色板

- **乐器**：**芯片音乐（chiptune）**——方波、三角波、噪声道；不要钢琴弦乐。
- **拟音**：8-bit 的「哔」「啵」跳跃声、拾取声、爆炸的噪声。
- **环境**：极简的循环底噪，或完全无环境声。
- **静默**：**至少一处**，音效停，只剩循环的底噪。
- **混音**：音效突出，音乐给节奏；响度 −14 LUFS。
- **人声**：可无，或用文字框代替；有则带轻微的失真质感。

## 8. 招牌动作

- **抖动渐变。** 一片区域从深到浅，**两种颜色的点阵一格一格交替**展开。
  *适合内容如：*一次过渡；一个层次的展开；时间的推移。

- **逐格点亮。** 形状**从一个角开始，一格一格点亮**，最后成形。
  *适合内容如：*一个产品的组装；一段内容的逐条出现；一次加载。

- **sprite 动画。** 角色的走路/跳跃循环，**明显抽帧**，有游戏的顿挫。
  *适合内容如：*一个角色的行动；一段流程的推进；游戏化的内容。

- **整数倍缩放。** 镜头**一档一档**放大/缩小（1x → 2x → 4x），不是连续缩放。
  *适合内容如：*从图形到格子的揭示；一次聚焦；一个层级的进入。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **像素大小不一** | 有的格子大有的小 | 写「统一的方形像素格，所有格子等大，无混用」 |
| **出现抗锯齿** | 斜线变平滑，有中间色 | 「硬边阶梯斜线，无抗锯齿，无中间色」 |
| **色板失控** | 出现几十上百色 | 「有限色板不超过 16 色，无色板外的颜色」 |
| **渐变变平滑** | 深浅变成连续渐变 | 「深浅过渡用抖动点阵（两色交替），非平滑混合」 |
| **变成低分辨率照片** | 是照片只是糊了 | 「矢量感的清晰图形，非模糊照片；格子是纯色」 |
| **退化成 3D** | 变成 3D 渲染 | 负面词必须有「不要 3D 渲染质感、不要平滑」 |

**该风格的默认退化项（负面词必备）**：
`不要抗锯齿，不要平滑渐变，不要连续色，不要 3D 渲染质感，不要照片，不要模糊，不要色板外的颜色`

## 10. 提示词配方

### 一句话版

```
16位像素画，统一方形像素格硬边无抗锯齿，16色有限色板，深浅过渡用抖动点阵，隔帧动画，卷轴式运镜。
```

### 完整版

```
{风格锚点}：16 位像素画（16 色有限色板）。
{材质与色彩}：统一的方形像素格（所有格子等大），硬边阶梯斜线，无抗锯齿无中间色；
深浅过渡用抖动点阵（两种颜色交替排列，非平滑混合）；色板不超过 16 色——
深 #1A1A2E、中 #4A4A6A、亮 #8A8AB0、主红 #E85D4A、主绿 #5A9E4A、主蓝 #3A6EA5、高光 #F5E6C8；
高对比，暗部很暗亮部很亮。
{主体与环境}：{主体}，{环境}，形状对齐像素网格，无半格。
{光照}：无体积光，明度靠色板的离散档位与抖动，非连续。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，明显抽帧（隔帧动画约 8–12fps），位移台阶式一格一格跳，
抖动格轻微闪烁，形状逐格点亮出现。
负面：不要抗锯齿，不要平滑渐变，不要连续色，不要 3D 渲染质感，不要照片，不要模糊，不要色板外的颜色。
```

**占位符填法**：
- `{主体}` → 「一个方块角色」「一座像素城市」「一把像素剑」
- `{环境}` → 「背景是抖动渐变的天空」「平台的地面是纯色块」
- `{运镜}` → 卷轴横移最贴游戏感

**最容易错**：像素大小不一；出现抗锯齿；渐变变平滑；色板超过 16 色。

## 11. 变化空间

**三个结构**
1. **逐格成形**：从一个角开始，格子逐个点亮，最后是一个完整的图形。
2. **卷轴推进**：镜头横向卷轴，依次经过三个场景，同一色板。
3. **缩放揭示**：从格子的极特写开始，一档一档拉远，露出完整的图形。

**三个开场**
1. 全黑，第一个格子亮起。
2. 抖动渐变的极特写，点阵在闪烁。
3. 一个 sprite 的行走循环，镜头跟着走。

**三个结尾**
1. 格子逐个熄灭，画面回到全黑。
2. 镜头拉远，图形缩成一个图标的大小。
3. 整数倍缩小到 1x，画面静止，UI 框浮现。
