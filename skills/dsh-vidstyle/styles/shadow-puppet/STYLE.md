# 皮影戏 — shadow-puppet

> 驴皮镂刻的影人，侧面造型，关节线缀，灯光把半透明的彩色投在白幕上。本风格做的是
> **「幕布后面的光」**——影人是剪影，颜色是透出来的，动是关节的机械感。
> 参考（只取语法）：传统皮影的**侧面造型与镂空刻法**；灯影下**透光色与剪影的对比**；
> 锣鼓点的**节奏切分**。不搬具体剧目、影人样谱与唱腔，成片里不点名。

## 1. 本质，以及它不是什么

1. **五分侧面**。影人几乎全是正侧面（或正面的极少），脸是一条轮廓线上的侧影——
   **不是正面，不是 3/4**。
2. **镂空透光**。影人身上有大量**镂空的花纹**，光从镂空处透出来，形成亮的花纹点。
3. **关节线缀**。肩、肘、腕、膝、腰都是**活动关节**，动起来有机械的分段感，
   不是连续的柔体。
4. **半透明的色**。影人的颜色是**透光的彩色**（红、绿、黄的半透明），不是不透明的色块。
5. **白幕与灯**。一切发生在一块被照亮的白幕上，影人在幕前（靠近观众）或幕后。

**不是什么**：不是剪纸（剪纸是平面贴纸，没有透光与关节），不是 3D 角色，不是真人演的
剪影（真人没有关节分段），不是矢量插画（皮影有刻刀的钝感与手工的不齐）。

## 2. 材质与质感

**基底**：白幕（亮子）。**被灯从后面照亮**，中心亮、四角略暗，可见布纹。

**材质**：
- 影人皮革 #8B6914 —— 驴皮本色，半透明，边缘有刻刀的钝感
- 透光红 #D4372A —— 衣饰的半透明红
- 透光绿 #2E8B57 —— 衣饰的半透明绿
- 透光黄 #E8B923 —— 饰物与镂空处的亮
- 幕布 #F0EAD8 —— 白幕的暖白
- 剪影黑 #1A1A1A —— 影人不透光的部分（头、关节、实心处）

**渲染逻辑**：**光从后方打来，穿过半透明皮革**，镂空处全透（最亮），实心处全挡（最暗），
半透明色处是**带色的光**。刻刀的边缘是**钝的、略有不齐**，不是矢量的锐边。
AI 生成对应「背光 + 半透明带色 + 镂空亮点 + 钝边」，不要「不透明色块 + 锐边」。

**必须锚在世界上的**：镂空的图案、关节的位置、幕布的布纹。**活在画面空间里的**：
背光的光晕与幕布的亮度渐变。

## 3. 色彩逻辑

**规则**：
- **剪影 + 三透光色**。影人的主体是剪影黑，只有衣饰与镂空处有透光红、绿、黄。
- **幕布是唯一的底**。全画面的底是被照亮的白幕 #F0EAD8，没有第二背景。
- **镂空处最亮**。光从镂空透出，是画面的亮点，点状分布。
- **不上的色**：渐变、阴影的多层次、任何写实的体积光。
- **明度排序**：镂空透光（最亮）→ 幕布 → 半透明色 → 皮革 → 剪影黑（最暗）。

**示例色板（仅示例）**：
`#F0EAD8 幕布 / #E8B923 透光黄 / #D4372A 透光红 / #2E8B57 透光绿 / #8B6914 皮革 / #1A1A1A 剪影`

## 4. 字体与字幕

- **标题**：楷体或隶书，**字形扁方**，字色用剪影黑 #1A1A1A，或像刻在幕上的字。
- **字幕**：细宋体，落在幕布的下缘，不压影人。
- **字号**：标题占画面高度 9%–12%，字幕 4%。
- **归属**：字幕像**戏台的题字**，在幕的边缘，不是浮在画面上的 UI。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**隔帧动画（on twos）**，约 12 fps——皮影是人手操作的，有停顿感。
- **缓动**：**起步突兀、中间匀速、收尾突兀**（机械感），不用柔顺的 s 曲线。
- **重量**：影人**轻**（是皮革），但关节有**机械的顿挫**。
- **抖动**：操作杆的轻微抖动（真实感），幅度小。
- **出现与消失**：影人**从幕的一侧走进来**，或被杆举着**从下方升上来**；消失时走出幕外。
- **什么永不动**：幕布、镂空图案、关节的结构。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 固定机位（正对戏台） | 观众视角、看戏、旁观 | 一段表演；一个被观看的场景 |
| 横向平移（跟着影人走） | 行进、追逐、一段路程 | 影人走路；一段旅程 |
| 缓慢推近至影人的脸 | 揭示、表情、情绪 | 一次情绪的变化；一个特写 |
| 缓慢拉远露出戏台全貌 | 揭示、全貌、幕后 | 从表演到幕后；一个格局 |
| 上下轻移（跟着操作杆） | 操作感、幕后、手工 | 幕后的手艺；一次操作 |

**取景规则**：影人在画面中下部（站在幕前），幕布占满背景；操作杆可露也可不露
（露杆更「真实」，不露更「戏剧」）。**允许的转场**：影人走出幕外、幕布落下、
镂空花纹放大遮挡。**禁止**：360° 环绕、快速甩镜、硬切到白天/实景。

## 7. 声音色板

- **乐器**：锣、鼓、板、胡琴/唢呐——**戏曲打击乐为主**，节奏切分明。
- **拟音**：影人关节的木质轻响、刻刀刻皮、幕布被风拂动、操作杆的摩擦。
- **环境**：戏台的空间感，观众的极轻动静（可选）。
- **静默**：**至少一处**，锣鼓停，只剩关节的轻响。
- **混音**：锣鼓给足冲击，人声在上方；响度 −14 LUFS。
- **人声**：戏曲念白的节奏感，或干净旁白反差。

## 8. 招牌动作

- **关节顿挫。** 影人的手臂**分段抬起**，肩、肘、腕依次到位，每段之间有停顿。
  *适合内容如：*一次操作演示；一个机械流程；手艺的展示。

- **镂空透光。** 镂空的花纹**被光打亮**，花纹点逐一亮起。
  *适合内容如：*一个图案的显现；一次装饰的展开；细节的强调。

- **影人入幕。** 影人从幕的一侧**走进画面**，先是一条轮廓，然后整个身体进来。
  *适合内容如：*一个角色登场；一个开场；一段内容的进入。

- **影子重叠。** 两个影人重叠，重叠处**颜色叠加**（红 + 绿 = 深褐）。
  *适合内容如：*一次相遇；两种观点的交叠；一个合成的结果。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **变成正面** | 影人长成正面或 3/4 | 显式写「正侧面轮廓，五分侧，非正面非 3/4」 |
| **关节不分明** | 变成连续的柔体 | 「关节分段明显，肩肘腕为活动关节，机械顿挫感」 |
| **变成剪纸** | 变成平面贴纸，无透光 | 「半透明皮革透光，镂空处全透，非不透明剪纸」 |
| **退化成 3D** | 变成 3D 角色渲染 | 负面词必须有「不要 3D 渲染质感、不要立体塑形」 |
| **镂空没了** | 变成实心色块 | 「身上有大量镂空花纹，光从镂空透出」 |
| **颜色太艳** | 变成不透明的鲜艳色 | 「颜色是透光的半透明色，非不透明色块」 |

**该风格的默认退化项（负面词必备）**：
`不要正面，不要 3/4 视角，不要 3D 渲染质感，不要立体塑形，不要不透明色块，不要照片级锐度，不要渐变阴影`

## 10. 提示词配方

### 一句话版

```
传统皮影戏，驴皮镂刻的正侧面影人，关节线缀分段动作，半透明彩色透光，白幕背光，镂空花纹透亮，隔帧动画。
```

### 完整版

```
{风格锚点}：传统皮影戏，灯影投在白幕上。
{材质与色彩}：半透明驴皮 #8B6914 透光，衣饰为透光红 #D4372A、透光绿 #2E8B57、透光黄 #E8B923，
身上大量镂空花纹（光从镂空处全透，最亮）；实心处为剪影黑 #1A1A1A；幕布 #F0EAD8 被背光照亮，
中心亮四角略暗；刻刀边缘钝而不齐，非矢量锐边。
{主体与环境}：{主体}，正侧面轮廓（五分侧，非正面非 3/4），{环境}，幕布占满背景。
{光照}：单一背光从幕后打来，穿过半透明皮革，镂空处最亮，实心处全挡。
{运镜}：{从 §6 表选一个，固定机位优先}。
{运动}：{主体动作}，关节分段抬起（肩→肘→腕依次到位，每段有停顿），隔帧动画约12fps，
操作杆轻微抖动，幕布静止。
负面：不要正面，不要 3/4 视角，不要 3D 渲染质感，不要立体塑形，不要不透明色块，不要照片级锐度，不要渐变阴影。
```

**占位符填法**：
- `{主体}` → 「一个举袖的影人」「两个对峙的影人」「一只展翅的凤」
- `{环境}` → 「白幕前的戏台」「幕布下缘可见台板」
- `{运镜}` → **优先「固定机位」**，皮影的戏剧感来自静止的看

**最容易错**：写成正面；关节没分段；颜色变成不透明；加了 3D 光影。

## 11. 变化空间

**三个结构**
1. **一出戏**：影人入幕 → 冲突 → 结局，固定机位看完。
2. **幕后揭示**：先演一段，镜头拉远，露出操作杆与灯，再回到表演。
3. **由影及人**：从影人的特写开始，逐步露出关节、杆、手，最后是手艺本身。

**三个开场**
1. 全黑，锣鼓一声，影人的轮廓先于身体入幕。
2. 幕布的布纹特写，背光亮起。
3. 镂空花纹的极特写，光从镂空透出。

**三个结尾**
1. 影人走出幕外，幕布空了，锣鼓收。
2. 镜头拉远，露出整个戏台与灯，画面暗下。
3. 幕布落下，遮住一切。
