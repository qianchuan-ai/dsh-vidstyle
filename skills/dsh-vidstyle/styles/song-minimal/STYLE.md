# 宋代极简 — song-minimal

> 单色釉瓷器与边角构图的宋人美学：汝窑天青、哥窑开片、马远夏圭的「一角半边」。本风格做的是
> **「少即是满」**——一个器物、一片留白、一道流动的光，就够。
> 参考（只取语法）：宋瓷单色釉的**釉面质感与开片**；南宋院体的**边角构图**与**留白即远景**。
> 不搬具体器形、款识与画作，成片里不点名。

## 1. 本质，以及它不是什么

1. **单色釉**。全画面只有一个色相的深浅变化，没有图案、没有花纹、没有第二色。
2. **开片**。釉面有细密的裂纹（冰裂纹），是**随机的、细的、不规则的**网状，不是噪点。
3. **边角构图**。主体压在画面一角（马远「一角」、夏圭「半边」），其余全部留白——留白是
   远景、是雾、是水。
4. **比例即美**。器物的轮廓线简洁精确，没有多余装饰，曲线的转折是唯一的设计。
5. **光是唯一的运动**。器物不动，动的是釉面上那道缓慢流动的高光。

**不是什么**：不是青花瓷（有图案），不是彩瓷（有第二色），不是 3D 产品渲染（没有摄影棚高光），
不是侘寂的粗糙（宋瓷是精致的），不是极简主义平面设计（有材质与光）。

## 2. 材质与质感

**基底**：釉面。半透明的玻璃质，底下透出胎土的灰白。**开片在釉层里**，不是画在表面。

**材质**：
- 汝窑天青 #7A99A8 —— 「雨过天青云破处」，偏灰的蓝，不鲜艳
- 哥窑灰青 #8C9490 —— 开片处颜色略深，形成「金丝铁线」
- 定窑白 #EDE6D8 —— 暖白，不是冷白
- 胎土灰 #B8B0A4 —— 器足露胎处
- 高光 #F5F2EA —— 釉面反射，**只有一道，窄而柔**

**渲染逻辑**：**釉是透明层，光从底下透上来**。开片是釉层收缩产生的裂，所以裂纹处颜色
略深、略凹。AI 生成对应「半透明釉层 + 底下透出胎色 + 细裂纹网」，不要「表面贴图」。

**必须锚在世界上的**：开片的走向、釉面的流动高光、器足的露胎。**活在画面空间里的**：
整体的低饱和冷调。

## 3. 色彩逻辑

**规则**：
- **一色到底**。全画面只有一个色相，靠明度分层次。允许的唯一「第二色」是器足的胎土灰。
- **留白占 50%–70%**。留白是画面的主体之一。
- **高光只有一道**，窄（约画面宽度的 3%–5%），柔，不锐。
- **不上的色**：任何图案色、纯黑 #000、纯白 #FFF、高饱和色、金色。
- **明度排序**：留白（最亮）→ 釉面亮部 → 釉面暗部 → 开片线（最暗，细线状）。

**示例色板（仅示例）**：
`#7A99A8 汝窑天青 / #8C9490 哥窑灰青 / #EDE6D8 定窑白 / #B8B0A4 胎土灰 / #F5F2EA 高光`

## 4. 字体与字幕

- **标题**：细宋体或仿宋，字重极细，字距拉开（字距约为字宽的 0.3 倍）。字色用釉色的深色
  #4A5A62，不用纯黑。
- **字幕**：同款细宋体，直接落在留白上，不加底条。
- **字号**：标题占画面高度 6%–8%，字幕 3.5%–4%。
- **归属**：字幕像**器物底下的款识**，小、偏、不抢。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**不抽帧**，连续平滑——瓷器是静的，抽帧会显得糙。
- **缓动**：**极慢的 ease-in-out**，几乎察觉不到。整支片子的运动总量极少。
- **重量**：**极重但静**。器物有分量感，但不移动；光在它上面流动。
- **抖动**：完全无抖动。任何抖动都破坏宋瓷的静。
- **出现与消失**：器物从留白里**渐显**（不是淡入，是像从雾里显形），或光扫过时显形。
- **什么永不动**：开片、器形轮廓、留白。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 极缓慢的水平横移 | 时间、并列、一段陈列 | 一组器物；一个流程的各步骤；四季 |
| 极缓慢推近至釉面开片 | 发现、珍视、细看 | 一个被忽略的工艺细节；一次鉴定 |
| 缓慢绕器物的小幅弧线（≤15°） | 端详、审视、全貌 | 一个产品的展示；一次评估 |
| 锁死画框 | 静物的凝视、留白的呼吸 | 一段静默；让观众自己看 |
| 缓慢上移（从器足到口沿） | 完整、交代、由下而上 | 一件作品的完整呈现；一个结论 |

**取景规则**：器物压在画面左下或右上角，占画面 1/3–1/2；留白 50%–70%；器物不居中。
**允许的转场**：留白淡出、光扫过显形、开片纹理蔓延遮挡。
**禁止**：快速运镜、环绕超过 20°、硬切到不同色温、任何抖动。

## 7. 声音色板

- **乐器**：古琴的散音（一个音，拖很长）、尺八的一个长音、瓷磬的轻击——**极简到近乎无乐**。
- **拟音**：瓷面被指腹轻触、开片在烧制中细微的「叮」声、水注入盏中。
- **环境**：极静的室内，几乎只有空气声。
- **静默**：**至少四处近乎全静**——这个风格的静默比声音重要。
- **混音**：音乐极轻，几乎贴地；响度 −14 LUFS。
- **人声**：慢，轻，停顿长。

## 8. 招牌动作

- **开片蔓延。** 釉面的裂纹从一点开始，**缓慢地、无声地**向四周蔓延成网。
  *适合内容如：*时间的痕迹；一次鉴定的展开；一个老物件的故事。

- **天青渐变。** 釉色从灰青缓慢过渡到天青，像雨后天色渐开。
  *适合内容如：*一个状态的转变；产品从无到有；一段情绪的转好。

- **光扫釉面。** 一道窄高光从器物的一侧缓慢扫到另一侧，扫过之处开片被照亮。
  *适合内容如：*一次揭晓；一个产品的 360° 展示（小幅）；一个重点被指出。

- **留白显形。** 一片空白里，器物的轮廓从雾中逐渐显出。
  *适合内容如：*一个开场；一段回忆；一个概念从无到有。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **开片变噪点** | 裂纹变成均匀噪点或规则网格 | 写「细密不规则的冰裂纹，疏密不均，非均匀网格」 |
| **器形不对称** | 碗口椭圆、线条歪斜 | 写「正视角度，器形对称，轮廓线精确」；避免俯拍透视 |
| **退化成 3D 渲染** | 变成摄影棚产品图，高光过硬 | 负面词必须有「不要摄影棚高光、不要 3D 渲染质感」 |
| **加了花纹** | 长出青花或彩绘 | 「不要任何图案、不要花纹、不要第二色」 |
| **留白没了** | 画面被填满 | 「留白占画面 60%，器物压在画面一角」 |
| **颜色太艳** | 变成鲜蓝 | 保留 hex 但注明「低饱和、偏灰、不鲜艳」 |

**该风格的默认退化项（负面词必备）**：
`不要任何图案花纹，不要第二色，不要 3D 渲染质感，不要摄影棚高光，不要照片级锐度，不要纯黑纯白，不要居中构图`

## 10. 提示词配方

### 一句话版

```
宋代单色釉瓷器美学，汝窑天青釉面带细密冰裂开片，边角构图大留白，一道柔和高光缓慢流动，极简无图案，非3D。
```

### 完整版

```
{风格锚点}：宋代单色釉瓷器美学，汝窑天青釉面。
{材质与色彩}：半透明玻璃质釉层，透出胎土 #B8B0A4，釉色 #7A99A8 低饱和偏灰，
细密不规则冰裂开片（疏密不均，非均匀网格），一道窄柔高光 #F5F2EA；全画面一色，无图案无花纹。
{主体与环境}：{主体}，压在画面{左下/右上}角，占画面 1/3，留白占 60%，{环境}。
{光照}：单一柔和侧光，高光窄而柔，无锐利反射。
{运镜}：{从 §6 表选一个，极缓慢}。
{运动}：器物静止不动，高光沿釉面极缓慢流动，开片纹理静止，连续平滑无抖动。
负面：不要任何图案花纹，不要第二色，不要 3D 渲染质感，不要摄影棚高光，不要照片级锐度，不要纯黑纯白，不要居中构图。
```

**占位符填法**：
- `{主体}` → 「一只汝窑天青釉茶盏」「一个哥窑灰青釉笔洗」「一件定窑白釉小瓶」
- `{环境}` → 默认「大面积留白」；需要时加「下方一抹极淡的灰影」
- `{运镜}` → **只选一个**，且必须是表里最慢的那档

**最容易错**：加了花纹；器物居中；开片写成「均匀纹理」；给了摄影棚高光。

## 11. 变化空间

**三个结构**
1. **一物到底**：一个器物，一支片子只有光在它上面流动，靠开片与釉色变化推进。
2. **并列陈列**：镜头横移，依次经过三件器物，同一构图规则，釉色各偏一档。
3. **由片及器**：从开片纹理的极特写开始，缓慢拉远，露出完整的器物。

**三个开场**
1. 全是留白，一道高光从画面边缘扫入。
2. 开片纹理的极特写，一声极轻的「叮」。
3. 灰青色的雾，器物轮廓从中缓慢显形。

**三个结尾**
1. 高光停在器物口沿，画面静止三秒，留白扩大。
2. 镜头缓慢拉远，器物缩成画面一角，留白占到 80%。
3. 釉色缓慢过渡到天青，画面渐隐入留白。
