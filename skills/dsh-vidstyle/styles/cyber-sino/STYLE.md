# 赛博中国 — cyber-sino

> 雨夜霓虹的中式赛博：汉字招牌、飞檐斗拱、全息数据流穿过年画与榫卯。本风格做的是
> **「传统构件 + 未来光」**的对撞——不是西方赛博换几个汉字，是中式构造本身在发光。
> 参考（只取语法）：东亚都市雨夜霓虹的**反射与湿面**；中式建筑的**飞檐斗拱与榫卯结构**；
> 传统装饰的**回纹与祥云节奏**。不搬具体城市、招牌文字与影视形象，成片里不点名。

## 1. 本质，以及它不是什么

1. **汉字是光源**。霓虹招牌是**汉字**，笔画本身发光，光会打湿地面与人的脸。
2. **中式构造在发光**。飞檐、斗拱、榫卯、窗棂——这些结构件被灯带勾出轮廓，
   不是贴上去的纹样。
3. **湿面反射**。雨后的地面、金属、玻璃，把霓虹拉成长条的倒影——**反射是画面的一半**。
4. **暗底高对比**。画面 60%–70% 是暗部（夜、雨、阴影），亮部只在霓虹与反射上，对比强烈。
5. **数据流是实体**。全息的光带、粒子、代码，**穿过**建筑构件，不是叠在上面。

**不是什么**：不是西方赛博（银翼杀手式的纯英文街景、和风元素），不是科幻机甲，
不是游戏 UI 界面，不是平面赛博海报（有纵深与雨）。

## 2. 材质与质感

**基底**：夜。空气中有雨丝与雾，霓虹在雾里**晕开**成光团。

**材质**：
- 霓虹红 #FF2D55 —— 主光源，招牌与灯带
- 霓虹青 #00E5FF —— 数据流与全息，与红形成冷暖对撞
- 霓虹金 #FFB300 —— 传统构件的勾边（斗拱、窗棂）
- 湿面反光 #1A1A2E —— 地面与玻璃的暗底，反射拉成长条
- 木构件 #4A3728 —— 飞檐斗拱的本色，被灯带勾亮

**渲染逻辑**：**光在湿面上反射并拉长**，霓虹在雾里**晕开成团**（不是硬边）。
数据流是**半透明的加法叠加**（additive），会盖住后面的建筑。
AI 生成对应「湿面长条反射 + 霓虹雾化晕开 + 半透明光带叠加」，不要「平贴的发光贴图」。

**必须锚在世界上的**：反射的走向、雾里的光晕、构件的结构。**活在画面空间里的**：整体的
冷暖对比与暗调。

## 3. 色彩逻辑

**规则**：
- **暗底 + 双霓虹**。暗部占 60%–70%，霓虹红与霓虹青是仅有的两个亮色，金色只给传统构件。
- **红青对撞**。红与青是互补，**不要中间的紫**（会变成廉价的蒸汽波）。
- **反射必须有**。地面、玻璃、金属至少一处有霓虹的长条倒影。
- **不上的色**：大面积的白、柔和的粉紫渐变、任何「梦幻」色调。
- **明度排序**：暗部（最暗）→ 湿面 → 木构件 → 金勾边 → 霓虹红/青（最亮）。

**示例色板（仅示例）**：
`#0B0B1A 夜底 / #1A1A2E 湿面 / #4A3728 木构 / #FF2D55 霓虹红 / #00E5FF 霓虹青 / #FFB300 霓虹金`

## 4. 字体与字幕

- **标题**：黑体或综艺体，**笔画粗、可发光**，字色霓虹红 #FF2D55 或青 #00E5FF，
  外发光（glow）半径约字高的 20%。
- **字幕**：细黑体，字色霓虹青，可加极细的发光边。
- **字号**：标题占画面高度 10%–14%，字幕 4%–5%。
- **归属**：字幕像**一块悬浮的全息牌**，不是压在画面上的平面字。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

**注意**：AI 生成汉字容易出错。**标题字尽量短（2–4 字）**，或用图形化处理；不确定时
让字幕在后期加，不进生成提示词。

## 5. 运动质感

- **抽帧感**：**不抽帧**，连续平滑——雨与光需要连贯。
- **缓动**：霓虹用**闪烁**（不规则的通断，不是规律闪烁）；数据流用**匀速**；
  运镜用 **ease-in-out**。
- **重量**：雨有重量（下落），光没有（弥漫），数据流**悬浮**。
- **抖动**：手持感的轻微抖动（幅度小），或完全稳定——**两种都要支持**，看题材。
- **出现与消失**：霓虹**逐笔点亮**（像通电），不是淡入；数据流从画面外**流进来**。
- **什么永不动**：建筑结构（飞檐斗拱的轮廓）、雨的方向。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 沿街的缓慢横移/推进 | 进入、探索、一段路程 | 走进一条街；一个环境的交代 |
| 仰角沿飞檐上摇 | 崇高、传统、结构之美 | 从街面到屋顶；一个构造的展示 |
| 穿过数据流的推进 | 沉入、连接、进入系统 | 从现实到数据；一次登录 |
| 低角度贴地推进（看反射） | 湿度、氛围、都市感 | 雨夜氛围；一段情绪 |
| 锁死画框（对称构图） | 庄严、门面、牌楼 | 一个入口；一次亮相 |

**取景规则**：飞檐常压画面上缘，街面占下 1/3（放反射）；招牌在画面中上部。
**允许的转场**：霓虹闪烁切换、数据流遮挡、雨幕遮挡、反射里的画面翻转。
**禁止**：纯白闪场、快速 360° 环绕、硬切到白天。

## 7. 声音色板

- **乐器**：电子合成 pad + 古筝/琵琶的拨弦采样——**中西对撞**，不要纯管弦。
- **拟音**：雨落在不同材质（金属、伞面、水面）、霓虹灯管的电流嗡鸣、数据流的高频扫过。
- **环境**：雨声底噪、远处的城市低频、偶尔的车流。
- **静默**：**至少一处**，雨声突然抽掉，只剩霓虹的电流声。
- **混音**：低频给足，霓虹的电流声做高频点缀；响度 −14 LUFS。
- **人声**：略带无线电质感，或干净的旁白反差。

## 8. 招牌动作

- **霓虹逐笔点亮。** 汉字招牌的笔画**一笔一笔通电亮起**，最后一笔闪两下才稳。
  *适合内容如：*一个品牌亮相；一段标题；一个开场。

- **数据流穿檐。** 半透明的青色数据带**从飞檐斗拱之间穿过**，构件被照亮。
  *适合内容如：*传统与科技的结合；一次升级；一个系统的接入。

- **雨中霓虹反射。** 一滴雨落在积水上，涟漪把霓虹的倒影**打碎又重聚**。
  *适合内容如：*一次扰动；一个转折；氛围段落。

- **全息展开。** 一个平面的全息图从中心**折叠展开**成三维，展开时带出内容。
  *适合内容如：*一个产品的展示；一次数据可视化；一个菜单/目录的出现。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **汉字乱码** | 招牌字写错、笔画变形 | **标题字控制在 2–4 字**；或写「招牌字模糊不可辨，只见光」；复杂的字后期加 |
| **变成西方赛博** | 出现英文招牌、日文元素 | 显式写「中式飞檐斗拱与汉字招牌，无英文无日文」 |
| **透视混乱** | 建筑结构接不上 | 写「正透视或一点透视，结构连续」；避免广角畸变 |
| **颜色变成蒸汽波** | 出现粉紫渐变 | 负面词必须有「不要粉紫渐变、不要梦幻色调」 |
| **反射没了** | 地面是干的 | 「雨后湿面，地面有霓虹长条倒影」 |
| **太亮** | 变成亮堂的科幻 | 「暗部占画面 60%–70%，亮部只在霓虹上」 |

**该风格的默认退化项（负面词必备）**：
`不要英文招牌，不要日文元素，不要粉紫渐变，不要梦幻色调，不要 3D 渲染质感，不要平面海报感，不要大面积白`

### 一句话版

```
中式赛博雨夜，汉字霓虹招牌与飞檐斗拱被灯带勾亮，湿面拉出长条倒影，红青霓虹对撞暗底高对比，数据流穿过建筑。
```

```
{主体与环境}：{主体}，{环境}，中式飞檐斗拱与汉字招牌，无英文无日文。
{光照}：霓虹是唯一光源，光在雾里晕开、在湿面上拉长反射；暗部占 60%–70%。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，雨持续下落，霓虹不规则闪烁，数据带匀速流动，连续平滑。
负面：不要英文招牌，不要日文元素，不要粉紫渐变，不要梦幻色调，不要 3D 渲染质感，不要平面海报感，不要大面积白。
```

**占位符填法**：
- `{主体}` → 「一个撑伞的行人」「一辆驶过的车」「檐角的一只铜铃」
- `{环境}` → 「雨夜的老街，两侧是飞檐与霓虹招牌」「牌楼下的积水」
- `{运镜}` → 从 §6 表选一个；想稳就用「锁死画框」

**最容易错**：招牌写太多字（会乱码）；颜色加了紫；没有反射；太亮。

## 11. 变化空间

**三个结构**
1. **由街入檐**：沿街推进，仰角上摇到飞檐，数据流从檐下穿出。
2. **雨滴微观**：从一滴雨的特写开始，落下、打碎倒影、涟漪展开成全景。
3. **通电过程**：一条街从全黑开始，霓虹逐笔点亮，最后整条街亮起来。

**三个开场**
1. 全黑，一声电流嗡鸣，第一个笔画亮起。
2. 积水里的霓虹倒影，镜头缓慢上移到真实的街。
3. 雨幕，透过雨丝看到模糊的霓虹团。

**三个结尾**
1. 霓虹逐笔熄灭，画面回到全黑。
2. 镜头拉远，整条街缩成远处的一点光。
3. 数据流盖过画面，青色渐满，收在品牌色上。
