# 油画厚涂 — impasto-oil

> 堆得很厚的油画颜料，笔触与画刀的脊在光下有真实的起伏，湿接湿地一次画完。本风格做的是
> **「颜料的物质」**——你看得见颜料有多厚，光在笔触的脊上走。
> 参考（只取语法）：后印象派的**笔触方向引导视线**；画刀平刮的**块面感**；
> 湿接湿（alla prima）的**一次完成**。不搬具体画作、签名与题材，成片里不点名。

## 1. 本质，以及它不是什么

1. **颜料有厚度**。笔触是**堆起来的**，有脊有谷，光在脊上亮、在谷里暗——这是油画
   最核心的特征，也是 AI 最容易做错的地方（AI 常画成平的纹理贴图）。
2. **笔触有方向**。每一笔都有走向，**笔触的方向引导视线**，跟着它看过去。
3. **湿接湿**。颜色在画布上**直接调和**，边缘有 wet-on-wet 的软混，不是干透后的硬叠。
4. **块面概括**。形体是用**笔触的块面**概括出来的，不是描出来的轮廓。
5. **丰富的灰**。油画能调出极复杂的灰（补色调和），画面里有大量的**高级灰**。

**不是什么**：不是水彩（没有水的边界），不是粉彩（没有粉末感），不是 3D 渲染
（没有 CG 的光滑），不是照片（笔触是可见的），不是厚涂的数字插画（数字厚涂太均匀）。

## 2. 材质与质感

**基底**：亚麻布。可见**织纹**，布纹在薄处透出来，厚处被颜料盖住。

**材质**：
- 钴蓝 #2A5CAA、镉红 #C0392B、镉黄 #E8A317 —— 高饱和的原色区
- 丰富的灰 #8A8578 —— 大面积的补色调和灰
- 熟褐 #6B4423 —— 暗部与底
- 铅白 #EDE8DC —— 高光堆得最厚
- 亚麻布 #C8BCA8 —— 薄处透出

**渲染逻辑**：**颜料堆叠，有脊有谷**。笔触的脊迎光亮，背光暗，形成**真实的起伏阴影**
（不是画出来的阴影）。厚处完全不透布纹，薄处透出来。
AI 生成对应「有起伏的颜料脊 + 方向性笔触 + 湿接湿的软边」，不要「平的纹理」。

**必须锚在世界上的**：笔触的方向、颜料的脊、布纹。**活在画面空间里的**：整体的暖旧调。

## 3. 色彩逻辑

**规则**：
- **原色区 + 灰区**。画面有几处**高饱和的原色**（一笔就够），其余是丰富的灰。
- **补色调和**。灰不是加白加黑调出来的，是**补色相加**（红+绿、蓝+橙），所以灰有温度。
- **厚薄对比**。高光与主体堆得最厚（颜料多），背景与暗部薄（颜料少，透布纹）。
- **不上的色**：纯黑 #000（暗部是熟褐加蓝）、纯白 #FFF（高光是铅白偏暖）、荧光色。
- **明度排序**：布纹（最亮，薄处）→ 灰区 → 原色区 → 熟褐暗部 → 最厚的铅白高光（最亮，厚处）。

**示例色板（仅示例）**：
`#C8BCA8 亚麻布 / #8A8578 丰富灰 / #2A5CAA 钴蓝 / #C0392B 镉红 / #6B4423 熟褐 / #EDE8DC 铅白`

## 4. 字体与字幕

- **标题**：**手写感的无衬线或粗衬线**，像用画笔写上去的，边缘有颜料的毛边。
  字色用熟褐 #6B4423 或铅白 #EDE8DC（压在暗部上）。
- **字幕**：细无衬线，落在灰区上，不加底条。
- **字号**：标题占画面高度 9%–12%，字幕 4%。
- **归属**：字幕像**画布边缘的标注**，不在画面中心。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**不抽帧**，但**每一帧的笔触都略有不同**（手绘的不完美），形成
  「沸腾」（boiling）的观感——这是动画里笔触风格的核心。
- **缓动**：笔触**起笔重、收笔轻**（像真的运笔）；整体运动走 ease-in-out。
- **重量**：颜料**有重量**，一笔下去是**压**上去的。
- **抖动**：笔触的沸腾（每帧微变），不是画面的抖动。
- **出现与消失**：形体**被笔触画出来**，一笔一笔堆起来；消失时被新的笔触盖住。
- **什么永不动**：布纹的方向、画面的整体构图。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 沿笔触方向的缓慢移动 | 运笔、观看的路径、一笔的完成 | 一段创作过程；一次观看 |
| 缓慢推近至最厚的高光 | 聚焦、珍视、细节 | 一个被强调的细节；一次凝视 |
| 缓慢拉远到全幅 | 全貌、完成、格局 | 一幅画的完成；一个结论 |
| 锁死画框 | 画面的凝视、构图本身 | 让观众看构图；一段静止 |
| 轻微的手持漂移 | 在画室里看画的临场感 | 一段临场；一次走动看画 |

**取景规则**：主体常压一角，笔触的方向**汇聚到主体**；高光堆得最厚处是视觉焦点。
**允许的转场**：一笔扫过、笔触沸腾变化、颜料堆叠遮挡。
**禁止**：快速甩镜、360° 环绕、硬切到完全不同的色温。

## 7. 声音色板

- **乐器**：大提琴的低音区、钢琴的单音、弦乐的长音——**古典但不铺满**，留呼吸。
- **拟音**：画笔擦布的沙沙、画刀刮过画布、颜料从管里挤出、调色刀碰调色盘。
- **环境**：画室的安静，窗外极远的市声。
- **静默**：**至少两处**，只有笔的声音。
- **混音**：音乐给情绪但不抢，笔的声音是主角之一；响度 −14 LUFS。
- **人声**：慢，像一边画一边说。

## 8. 招牌动作

- **一笔扫过。** 一笔从画面一侧扫到另一侧，**脊与谷同时出现**，带出下一个形体。
  *适合内容如：*一次转场；一个流程的推进；一段内容的翻页。

- **颜料堆叠。** 同一处**一层一层堆上去**，越来越厚，最后高光亮起来。
  *适合内容如：*一个概念的加深；一次积累；情绪的叠加。

- **画刀平刮。** 画刀**一刀平刮过去**，把底下的颜色刮出来，形成块面。
  *适合内容如：*一次揭示；一个块面的出现；果断的转折。

- **沸腾显影。** 形体的笔触**每帧微变**（沸腾），像画在动。
  *适合内容如：*一个形象的活动；一段记忆的不稳定；梦境感。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **笔触变平** | 变成平的纹理贴图，没有起伏 | 写「颜料堆厚有脊有谷，光在脊上亮在谷里暗，有真实起伏」 |
| **笔触方向乱** | 笔触乱走，不引导视线 | 「笔触方向汇聚向主体，方向一致」 |
| **变成照片** | 变成写实照片 | 负面词必须有「不要照片级锐度、不要写实质感」 |
| **退化成 3D** | 变成 3D 渲染的厚涂 | 「不要 3D 渲染质感、不要 CG 光滑」 |
| **灰太脏** | 灰色发闷 | 「灰是补色调和的高级灰，有温度，非加黑白」 |
| **厚薄一样** | 全画面一样厚 | 「高光与主体堆得最厚，背景薄透布纹」 |

**该风格的默认退化项（负面词必备）**：
`不要照片级锐度，不要写实质感，不要 3D 渲染质感，不要平滑纹理，不要纯黑纯白，不要均匀厚度`

## 10. 提示词配方

### 一句话版

```
厚涂油画，颜料堆厚有脊有谷光在脊上走，笔触方向汇聚向主体，湿接湿软边，丰富补色灰，布纹在薄处透出。
```

### 完整版

```
{风格锚点}：厚涂油画，湿接湿一次完成。
{材质与色彩}：颜料堆厚有脊有谷（光在脊上亮、谷里暗，有真实起伏，非平的纹理）；
笔触方向汇聚向主体；湿接湿软边；高饱和原色区 #2A5CAA 钴蓝 / #C0392B 镉红 只点几处，
其余为补色调和的丰富灰 #8A8578（有温度，非加黑白）；高光堆最厚 #EDE8DC，
背景薄处透出亚麻布纹 #C8BCA8；暗部为熟褐 #6B4423 加蓝，无纯黑。
{主体与环境}：{主体}，{环境}，主体压画面一角，笔触汇聚向它。
{光照}：光在颜料脊上形成真实的起伏高光，非画出来的阴影。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，笔触每帧微变（沸腾感），起笔重收笔轻，连续平滑。
负面：不要照片级锐度，不要写实质感，不要 3D 渲染质感，不要平滑纹理，不要纯黑纯白，不要均匀厚度。
```

**占位符填法**：
- `{主体}` → 「一片厚重的云」「一张侧脸」「一堆静物的水果」
- `{环境}` → 「远处是薄透布纹的灰天空」「桌面是熟褐的暗」
- `{运镜}` → 缓慢推近至高光最厚处，最贴这个风格

**最容易错**：笔触写成「纹理」而不是「有起伏的脊」；灰写成加黑白；全画面一样厚。

## 11. 变化空间

**三个结构**
1. **一笔成形**：从一笔开始，逐笔堆出一个形体，最后镜头拉远看全幅。
2. **由薄及厚**：从薄透布纹的底开始，一层层堆厚，最后高光亮起来。
3. **画刀重构**：画到一半，画刀一刀刮掉，重新堆，第二次更概括。

**三个开场**
1. 全是布纹，一笔颜料压上去。
2. 画刀的极特写，一刀平刮，刮出底下的颜色。
3. 最厚的高光特写，镜头拉远露出全幅。

**三个结尾**
1. 最后一笔落下，笔触沸腾渐止，画面静止。
2. 镜头拉远，画缩成画架上的一幅，画室显露。
3. 画刀刮过画面，颜料被刮平，收在布纹上。
