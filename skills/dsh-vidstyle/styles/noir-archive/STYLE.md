# 黑白电影 — noir-archive

> 高对比的黑白胶片，低调照明切出窄亮部，百叶窗的影子打在人脸上，银盐颗粒一直在。本风格做的是
> **「光是刀」**——大面积的暗，只给一小条亮，形体是被光切出来的。
> 参考（只取语法）：黑色电影的**低调照明与百叶窗影**；德国表现主义的**倾斜角度与硬影**；
> 银盐胶片的**颗粒与暗角**。不搬具体影片、演员与情节，成片里不点名。

## 1. 本质，以及它不是什么

1. **低调照明（low-key）**。画面 60%–75% 是**暗部**，亮部只占一小条——
   光是**切**出形体的，不是照亮相体的。
2. **硬光与深影**。光源是**硬的**（直射），影子边缘清晰、很深，**影子本身是构图的一部分**。
3. **百叶窗影**。标志性的**条状影子**打在人脸、墙、地上——这是 noir 的签名。
4. **银盐颗粒**。画面有**持续的胶片颗粒**，在暗部尤其明显，**每帧都在动**。
5. **倾斜与封闭**。构图常**倾斜**（dutch angle），空间**封闭**（门框、走廊、窗），
   有压迫感。

**不是什么**：不是普通黑白照片（noir 是**有照明设计**的黑白，不是彩色去色），
不是高调（high-key）的明亮黑白，不是 3D 渲染，不是现代的「复古滤镜」（滤镜没有
照明设计与颗粒的运动）。

## 2. 材质与质感

**基底**：胶片。**银盐颗粒**持续在动（每帧不同），暗部颗粒最明显。

**材质**：
- 深黑 #0A0A0A —— 暗部，**大面积**，几乎无细节
- 中灰 #6A6A6A —— 中间调，有细节
- 亮部 #D8D8D8 —— 硬光切出的亮
- 高光 #F2F2F2 —— 最亮，只在光源直射处（小面积）
- 颗粒 —— 持续的银盐颗粒，暗部明显
- 暗角 —— 四角压暗，中心亮

**渲染逻辑**：**硬光切形**。光源直射的地方亮，其余迅速掉进暗部（**没有中间的过渡带**，
这是 noir 和普通黑白的区别）。影子边缘清晰。颗粒每帧重生成。
AI 生成对应「硬光 + 深影 + 快速的明暗截止 + 颗粒每帧动」，不要「平滑的灰阶过渡」。

**必须锚在世界上的**：影子的形状、颗粒的运动、暗角。**活在画面空间里的**：
整体的明暗分布与倾斜。

## 3. 色彩逻辑

**规则**：
- **只有灰**。全画面是灰阶，**没有彩色**（连微弱的色调都没有）。
- **暗部占 60%–75%**。暗部**几乎没有细节**（这是设计，不是欠曝）。
- **亮部窄而硬**。亮部是**条状或块状**的，边缘清晰。
- **不上的色**：任何彩色、平滑的灰阶过渡、高调的明亮。
- **明度排序**：高光（最亮，小面积）→ 亮部 → 中灰 → 暗部 → 深黑（最暗，大面积）。

**示例色板（仅示例）**：
`#0A0A0A 深黑 / #2A2A2A 暗部 / #6A6A6A 中灰 / #A8A8A8 亮灰 / #D8D8D8 亮部 / #F2F2F2 高光`

## 4. 字体与字幕

- **标题**：**粗衬线或装饰艺术（Art Deco）风格的无衬线**，字形**高瘦、字距紧**，
  有 40 年代片头的气质。字色用亮部 #D8D8D8，压在暗部上。
- **字幕**：细无衬线，落在暗部上，不加底条（暗部本身就是底）。
- **字号**：标题占画面高度 10%–14%，字幕 4%–5%。
- **归属**：字幕像**老式片头的字幕卡**，居中或下缘。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**不抽帧**，但**颗粒每帧重生成**（这是运动的来源）。
- **缓动**：**慢而稳**，或**突然的停顿**（悬疑感）；不用轻快的曲线。
- **重量**：**重**。人物动作沉，影子跟着沉。
- **抖动**：**颗粒的抖动**（每帧微变），不是画面的抖动。
- **出现与消失**：**从暗部里显形**（光扫过来才看见），不是淡入。
- **什么永不动**：封闭空间的结构（门框、窗）、影子的方向（除非光动）。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 缓慢推进（穿过门框/走廊） | 逼近、深入、进入险境 | 一次逼近；一个空间的深入；一段悬疑 |
| 缓慢后拉（从脸到空间） | 揭示、孤立、处境 | 从个人到处境的揭示；一次孤立 |
| 倾斜角度的缓慢移动 | 不安、失衡、危机 | 一次不安；一个转折前的失衡 |
| 锁死画框（封闭构图） | 困住、无处可逃、静止 | 一段对峙；一次被困 |
| 横向平移（跟着人走） | 追踪、跟随、跟踪 | 一次跟踪；一段行走 |

**取景规则**：**封闭构图**（门框、窗、走廊占画面边缘）；**倾斜 5–15°**；
主体常被影子**切掉一半**。**允许的转场**：影子遮挡、光扫过、穿过门框。
**禁止**：明亮的高调照明、快速甩镜、360° 环绕、彩色。

## 7. 声音色板

- **乐器**：低音提琴的拨弦（walking bass）、萨克斯的低音区、钢琴的不协和和弦——
  **爵士与悬疑**，不要宏大的管弦。
- **拟音**：脚步在空走廊的回响、门轴的吱呀、雨打窗、打火机的咔哒。
- **环境**：雨声、远处的警笛、室内空调的低频。
- **静默**：**至少两处**，雨声停，只剩呼吸。
- **混音**：低频给足，雨声是底；响度 −14 LUFS。
- **人声**：低，近麦，像在耳边说。

## 8. 招牌动作

- **百叶窗影扫过。** 条状影子**从脸上缓慢扫过**，明暗交替。
  *适合内容如：*一次情绪的变化；一个揭示；时间的推移。

- **烟雾中的光束。** 一束硬光穿过烟雾，**光束的边缘清晰**，烟在光里缓慢动。
  *适合内容如：*一次登场；一个空间的交代；悬疑的氛围。

- **从暗部显形。** 光扫过来，**原本看不见的东西显形**（一个人、一件物证）。
  *适合内容如：*一次发现；一个揭晓；一个线索的出现。

- **影子先于人。** 影子**先出现在墙上**，然后人才走进画面。
  *适合内容如：*一次逼近；一个威胁的临近；一个开场。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **变成去色照片** | 是彩色照片转黑白，没有照明设计 | 写「低调照明，硬光切形，有明确的光源方向」 |
| **灰阶太平滑** | 明暗之间有平滑过渡 | 「明暗快速截止，无中间过渡带，影子边缘清晰」 |
| **暗部有细节** | 暗部被提亮，能看到东西 | 「暗部占 60%–75%，几乎没有细节（设计如此，非欠曝）」 |
| **颗粒没了** | 画面太干净 | 「持续的银盐颗粒，暗部明显，每帧重生成」 |
| **退化成 3D** | 变成 3D 渲染的黑白 | 负面词必须有「不要 3D 渲染质感、不要 CG 光滑」 |
| **变成高调** | 画面太亮 | 「低调照明，暗部占大面积，亮部只占一小条」 |

**该风格的默认退化项（负面词必备）**：
`不要彩色，不要高调明亮，不要平滑灰阶过渡，不要 3D 渲染质感，不要照片级锐度，不要暗部提亮，不要无颗粒`

## 10. 提示词配方

### 一句话版

```
黑色电影黑白胶片，低调照明暗部占七成硬光切形，百叶窗条状影，银盐颗粒每帧动，倾斜封闭构图，暗角。
```

### 完整版

```
{风格锚点}：40 年代黑色电影，黑白胶片。
{材质与色彩}：只有灰阶无彩色；暗部 #0A0A0A 占画面 70%（几乎无细节，是设计非欠曝），
亮部 #D8D8D8 窄而硬（条状或块状，边缘清晰）；明暗快速截止，无中间平滑过渡带；
硬光切出形体，影子边缘清晰、深；持续的银盐颗粒（暗部明显，每帧重生成）；四角暗角。
{主体与环境}：{主体}，{环境}，封闭构图（门框/窗/走廊占边缘），倾斜 5–15°，
主体被影子切掉一半。
{光照}：单一硬光源，方向明确，{百叶窗条影/侧光/顶光}，大面积暗部。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，动作沉稳缓慢，颗粒每帧重生成，影子随光，从暗部显形。
负面：不要彩色，不要高调明亮，不要平滑灰阶过渡，不要 3D 渲染质感，不要照片级锐度，不要暗部提亮，不要无颗粒。
```

**占位符填法**：
- `{主体}` → 「一个戴帽的男人侧影」「桌上的一个物件」「走廊尽头的人」
- `{环境}` → 「百叶窗后的房间」「雨夜的街道」「空旷的走廊」
- `{光照}` → 三选一：百叶窗条影（最经典）、侧光（切轮廓）、顶光（压迫）

**最容易错**：写成去色照片（没有光源方向）；暗部被提亮；颗粒没了；画面太亮。

## 11. 变化空间

**三个结构**
1. **一条走廊**：镜头沿封闭走廊推进，光影交替，尽头有人。
2. **一件物证**：从桌面物件的特写开始，光扫过，镜头拉开揭示空间。
3. **一次对峙**：两个影子在墙上先交锋，然后人进入画面。

**三个开场**
1. 全黑，一束光穿过烟雾，第一个形体显形。
2. 百叶窗影的极特写，条影缓慢扫过。
3. 一个倾斜的空房间，雨声，然后影子先出现。

**三个结尾**
1. 光熄灭，画面全黑，只剩雨声。
2. 镜头后拉，人缩成暗部里的一个小轮廓。
3. 门关上，影子被门缝切掉，画面收成一条亮线。
