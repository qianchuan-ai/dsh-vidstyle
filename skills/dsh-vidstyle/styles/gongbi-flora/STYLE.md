# 工笔花鸟 — gongbi-flora

> 绢本上的细笔设色花鸟，三矾九染叠出半透明的层次，鸟羽用丝毛一根根劈出。本风格做的是
> **「静中之动」**——花枝几乎不动，动的只有鸟的一个瞬间姿态。
> 参考（只取语法）：宋代院体花鸟的**折枝构图**与**丝毛法**；恽寿平没骨花的**撞水撞粉**。
> 不搬具体画作、题款与印文，成片里不点名。

## 1. 本质，以及它不是什么

1. **折枝构图**。不画全株，只截取一枝，从画面一角斜入，大量留白——留白是构图的一部分，
   不是没画完。
2. **丝毛**。鸟的羽毛是**一根一根劈出来的细线**，不是色块，不是渲染。
3. **三矾九染的半透明**。颜色是一层一层薄薄罩上去的，能透见底下的绢纹，所以颜色**沉而不闷**。
4. **静中之动**。花与枝基本不动，动的只有鸟——转头、欲飞未飞、爪子收紧。
5. **勾线极细**。高古游丝描，线细如丝、匀力、不断，不用提按变化。

**不是什么**：不是写意水墨（没有晕染冲撞），不是油画（没有厚涂与笔触），不是 3D 渲染，
不是现代插画的平涂（没有均匀色块），不是浮世绘（没有木刻的钝感边）。

## 2. 材质与质感

**基底**：绢或熟宣，可见**经纬织纹**，颜色透出织纹。绢本偏暖黄 #E8DCC8，纸本偏白。

**颜料**：
- 植物色（半透明）：花青 #3A5F8A、藤黄 #D4AF37、胭脂 #B5485A、汁绿 #6B8E5A
- 矿物色（覆盖）：蛤白 #F2EDE3、石绿 #7FA88B、赭石 #9C6B4A
- 墨 #2B2B2B —— 只用于勾线与鸟的焦墨处，不用于大面积渲染

**渲染逻辑**：**先勾后染，薄染多遍**。先用淡墨勾出轮廓，再一层层罩染，每层干透再上下一层。
AI 生成对应「多层半透明叠加，能透见底」，不要「一次到位的均匀色块」。

**必须锚在世界上的**：绢纹、丝毛的方向、花瓣的脉络。**活在画面空间里的**：整体的暖黄色调。

## 3. 色彩逻辑

**规则**：
- **植物色为主，矿物色为辅**。大面积用半透明植物色，只有花蕊、鸟羽高光用矿物色提亮。
- **花可艳，鸟不可艳**。花允许胭脂、藤黄，鸟只用墨、赭石、花青的深浅——**鸟是画面的定音**。
- **留白即色**。留白占画面 40%–60%，是构图的呼吸。
- **不上的色**：纯黑 #000、纯白 #FFF、荧光色、高饱和紫粉。
- **明度排序**：留白（最亮）→ 绢底 → 植物色 → 墨线（最暗，点状）。

**示例色板（仅示例）**：
`#E8DCC8 绢底 / #3A5F8A 花青 / #B5485A 胭脂 / #6B8E5A 汁绿 / #D4AF37 藤黄 / #2B2B2B 墨`

## 4. 字体与字幕

- **标题**：瘦金体或细宋体，取其**瘦硬挺拔**。字色用墨 #2B2B2B 或胭脂 #B5485A（作印章）。
- **字幕**：细宋体，字重偏轻，不加底条——直接落在留白上。
- **字号**：标题占画面高度 7%–10%，字幕 4%。
- **归属**：字幕像**画上的题款**，竖排更贴（从右向左），但横排也可接受。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：**不抽帧**，连续平滑（on ones）——工笔是精细活，抽帧会显得糙。
- **缓动**：极慢的 s 曲线，几乎察觉不到起步与收尾。
- **重量**：**极轻**。花瓣不飘落（除非专门设计），鸟不振翅（除非设计欲飞）。
- **抖动**：绢纹不动，花枝**微微随风**（幅度极小，约画面高度的 1%）。
- **出现与消失**：花从留白里**被丝毛勾出来**，不是淡入。
- **什么永不动**：留白、绢纹、勾线。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 极缓慢的横向平移（手卷式） | 时间、四季、一段并列 | 四季更替；一组并列的物产；一段流程 |
| 极缓慢推近至花蕊/鸟眼 | 凝视、珍视、发现 | 一个被忽略的细节；一次相遇 |
| 沿折枝方向的斜向移动 | 生长、延伸、来处 | 从枝到花的生长；一个来源 |
| 锁死画框 | 静物的「看」、留白的呼吸 | 让观众自己看；一段静默 |
| 缓慢下移（从花到鸟） | 落定、安顿、归处 | 一个结论；一次落地 |

**取景规则**：折枝从画面一角（左下或右上）斜入，占画面 1/3–1/2，其余留白；鸟常在枝头或
画面另一角，与花形成对角。**允许的转场**：留白淡出、折枝生长、花瓣遮挡。
**禁止**：快速甩镜、360° 环绕、硬切到不同色温。

## 7. 声音色板

- **乐器**：古琴（散音与泛音）、箫、琵琶的轮指——**极简**，不要钢琴弦乐铺底。
- **拟音**：鸟羽摩擦、爪子收紧绢面、花瓣落地（极轻）、绢被风拂动。
- **环境**：极静，几乎只有底噪；偶尔一声远处的鸟。
- **静默**：**至少三处近乎全静**——留白要配静默。
- **混音**：音乐极轻，闪避明显；响度 −14 LUFS。
- **人声**：慢，轻，像耳语。

## 8. 招牌动作

- **丝毛显影。** 鸟的羽毛从色块里**一根根劈出来**，细线逐渐显形。
  *适合内容如：*一个工艺的精细度展示；一个人物的「慢慢显出真容」；一段需要体现耐心的内容。

- **撞水撞粉。** 花瓣上水与粉相撞，颜色在绢面上自然晕开又停住（没骨法）。
  *适合内容如：*一次变化的发生；一个概念从模糊到清晰；饮品/美妆的质感展示。

- **折枝入画。** 一枝花从画面边缘**斜着长进来**，一路开花。
  *适合内容如：*一个开场；一段生长类叙事；列表式内容的逐条出现。

- **鸟欲飞未飞。** 鸟身体前倾、翅膀微张但没起飞，停在这个将发未发的瞬间。
  *适合内容如：*一次犹豫；一个临界点；产品「即将上市」的暗示。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **鸟崩** | 脚趾数量错、羽毛方向乱、头身比例失调 | 写「鸟的侧影，羽毛方向一致」；用中景不给爪子特写 |
| **花结构错** | 花瓣数量不对、花蕊位置乱 | 写具体的花名（「一朵半开的山茶」）而不是「花」 |
| **退化成水墨** | 变成晕染冲撞的写意 | 负面词必须有「不要水墨晕染、不要冲撞效果」 |
| **退化成 3D** | 变成 3D 渲染的花 | 「不要 3D 渲染质感、不要立体塑形、不要 CG 光泽」 |
| **留白没了** | 画面被填满 | 显式写「留白占画面一半以上，构图偏一角」 |
| **颜色太艳** | 变成现代插画平涂 | 写「颜色半透明，能透见绢纹，沉而不艳」 |

**该风格的默认退化项（负面词必备）**：
`不要水墨晕染，不要冲撞效果，不要 3D 渲染质感，不要照片级锐度，不要油画笔触，不要平涂色块，不要纯黑纯白`

## 10. 提示词配方

### 一句话版

```
宋代院体工笔花鸟，绢本设色，折枝构图大留白，丝毛细笔，颜色半透明透见绢纹，极缓慢运镜，非水墨非3D。
```

### 完整版

```
{风格锚点}：宋代院体工笔花鸟，绢本设色。
{材质与色彩}：高古游丝描勾线，三矾九染多层半透明罩染，能透见绢纹 #E8DCC8；
花青 #3A5F8A、胭脂 #B5485A、汁绿 #6B8E5A 为主，墨 #2B2B2B 只勾线，留白占画面一半以上。
{主体与环境}：{主体}，{环境}，折枝从画面一角斜入，构图偏一角。
{光照}：无明确光源，画面自发光，明度由留白到墨线逐层递减。
{运镜}：{从 §6 表选一个，极缓慢}。
{运动}：花枝随风极轻微摆动（幅度约画面高度1%），鸟{动作}，连续平滑不抽帧。
负面：不要水墨晕染，不要冲撞效果，不要 3D 渲染质感，不要照片级锐度，不要油画笔触，不要平涂色块，不要纯黑纯白。
```

**占位符填法**：
- `{主体}` → 「一朵半开的山茶与一只山雀」「枝头的白头翁」「折枝上的红蓼与蜻蜓」
- `{环境}` → 「身后大面积留白」为主；需要时加「远处淡赭石的坡岸」
- `{运动}` → 鸟的动作：「侧头」「欲飞未飞，翅膀微张」「爪子收紧」

**最容易错**：把留白填满；写成水墨（加了晕染）；给鸟爪特写。

## 11. 变化空间

**三个结构**
1. **四季并列**：镜头横移，依次经过春花、夏荫、秋实、冬枝，同一构图规则。
2. **由花及鸟**：先给花的特写，镜头缓慢下移，露出枝头的鸟。
3. **一幅完成**：从留白开始，丝毛与勾线逐笔显影，最后是一幅完整的画。

**三个开场**
1. 全是留白，一笔淡墨勾线从画面边缘画进来。
2. 绢纹特写，一滴胭脂落在绢上，撞开成花瓣。
3. 一只鸟先入画，停在空无一物的枝头，花随后长出。

**三个结尾**
1. 鸟飞出画面，镜头留在空枝与留白上。
2. 画面收进一枚印章的大小，落款浮现。
3. 花瓣落尽，只剩折枝，留白扩大到画面 4/5。
