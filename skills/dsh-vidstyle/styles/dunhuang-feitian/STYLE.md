# 敦煌飞天 — dunhuang-feitian

> 矿物料绘于泥壁的佛教壁画，飞天不生双翼、全凭飘带与动势腾空。本风格做的是壁画的**物质感**——
> 粗糙壁面、对比强烈的石青石绿与土红、铁线描的匀力线条——而不是现代插画的光滑。
> 参考（只取语法）：莫高窟北朝至唐代洞窟的造型与用色，取其**凹凸晕染**与**飘带动势**；
> 敦煌织物纹样，取其**联珠与忍冬的边饰节奏**。不搬具体窟号、经变故事与人物身份，成片里不点名。

## 1. 本质，以及它不是什么

1. **飘带即飞行**。飞天没有翅膀，全靠两三条长飘带的走向交代腾空与方向——飘带是这个风格的
   运动核心，不是装饰。
2. **矿物料的粉质感**。石青、石绿、朱砂是**不透明的矿物颗粒**，覆盖在土红底上，边缘没有
   渐变过渡，是**叠压**不是融合。
3. **铁线描的匀力轮廓**。人物与飘带的勾线粗细基本一致、有力、不断笔，不模仿毛笔的提按。
4. **壁面的物质**。画面底下永远有一层粗糙泥壁与白灰，颗粒透上来，颜色因此不纯净。
5. **强烈的补色对比**。石青／石绿（冷）对土红／朱砂（暖），几乎不用中间调和。

**不是什么**：不是 3D 渲染的佛像，不是现代国潮插画的光滑渐变，不是写实油画的体积光，
不是日本浮世绘的平面色块（浮世绘没有壁面颗粒，且线条是木刻的钝感）。

## 2. 材质与质感

**基底**：泥壁 + 白灰层，颗粒粗，可见细小孔洞与裂纹。整幅画必须透出这层底，颜色因此发闷、
不鲜艳——**颜色越靠边越剥落**。

**颜料**：
- 石青（azurite）#2E5A8C、石绿（malachite）#4A7A5C —— 不透明，覆盖力强，边缘硬
- 朱砂 #C0392B、土红 #A0522D —— 暖底与主色
- 铅白 #E8E2D5 —— 已氧化处发黑（**这个「变黑」是风格特征，不是错误**）
- 金 #C9A227 —— 只用于佛光、饰物、飞天的项圈手镯

**渲染逻辑**：**叠压，不融合**。先铺土红底，再压石青石绿，最后勾铁线描。AI 生成时对应
「不透明色块 + 硬边 + 后勾线」，不要「水彩渐变」。

**必须锚在世界上的**：飘带的走向、壁面的颗粒、剥落。**活在画面空间里的**：整体的暖旧色调、
轻微暗角。

## 3. 色彩逻辑

**规则**：
- **三主色一金**：石青、石绿、朱砂为三主，金只给佛光与饰物，不进背景。
- **土红打底**：所有画面的底色是土红 #8B4A32，冷色压在暖底上，所以冷色也带暖意。
- **铅白必氧化**：白的地方允许发黑，这是年代感的来源。
- **不上的色**：纯黑 #000、纯白 #FFF、荧光色、任何高饱和的紫与粉。
- **明度排序**：壁面（暗）→ 土红底 → 石绿石青（中）→ 朱砂（亮）→ 金（最亮，点状）。

**示例色板（仅示例，按题材调整）**：
`#8B4A32 土红底 / #2E5A8C 石青 / #4A7A5C 石绿 / #C0392B 朱砂 / #C9A227 金 / #E8E2D5 氧化铅白`

## 4. 字体与字幕

- **标题**：隶书或魏碑，取其**方硬古拙**，不要圆润的行楷。字色用氧化铅白 #E8E2D5 或金 #C9A227。
- **正文/字幕**：仿宋或宋体，字重偏细，字幕底用半透明土红条，不用纯黑条。
- **字号**：标题占画面高度 8%–12%，字幕 4%–5%。
- **归属**：字幕像是**写在壁面上的题记**，不是压在画面上的 UI——边缘略糙，不加投影。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

## 5. 运动质感

- **抽帧感**：隔帧动画（on twos），约 12 fps 的观感，飘带与衣褶逐帧变化——壁画是**一笔一笔
  叠出来的**，不是连续插值。
- **缓动**：飘带走**弧线**，起步慢、中段快、收尾又慢（s 曲线），永不用线性。
- **重量**：**无重力**。飞天不下坠，飘带不垂落，一切靠动势不靠重力。
- **抖动**：壁面的颗粒**永远不动**（它是底），动的只有飘带与人物。
- **出现与消失**：人物从飘带的走向里**被带出来**，不是淡入；消失时被飘带卷走。
- **什么永不动**：壁面颗粒、剥落、边饰纹样。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 缓慢横移（手卷式，右→左） | 时间、朝圣、一段历程 | 朝圣旅程；经变的展开；一组并列的场景 |
| 缓慢推近至飞天面部 | 揭示、亲近、凝视 | 一次相遇；一个被记住的细节 |
| 沿飘带走向的跟随移动 | 腾空、引导、飞升 | 从地面到天界；一个念头升起 |
| 锁死画框 | 壁画的「看」、凝视、供养 | 一个静止的瞬间；让观众自己看 |
| 轻微仰角固定 | 崇高、仰望、窟内视角 | 进入洞窟；仰望藻井 |

**取景规则**：飞天通常位于画面上 2/3（天界），地面/供养人位于下 1/3；边饰纹样贴画面四边，
宽约画面短边的 1/12。**允许的转场**：飘带扫过画面、镜头沿飘带飞出、花瓣散落遮挡。
**禁止**：硬切到完全不同的色温、360° 环绕、快速甩镜（破坏壁画的凝视感）。

## 7. 声音色板

- **乐器**：琵琶（轮指与扫弦）、箜篌、笛、筚篥、羯鼓——**敦煌壁画乐器**的音色，不要钢琴弦乐。
- **拟音**：壁面剥落的细碎声、飘带掠过的风、花瓣落地、金箔轻响。
- **环境**：窟内的低频空洞感、远处的风沙。
- **静默**：至少两处近乎全静，只留风声——飞天出现前的静最重要。
- **混音**：闪避明显，人声在音乐上方约 10 dB；响度 −14 LUFS。
- **人声**：慢，字与字之间留空，像诵读。

## 8. 招牌动作

- **飘带一甩带出转场。** 飘带从画面一侧横扫而过，扫过之处下一个场景显现。
  *适合内容如：*一支产品从古代工艺过渡到现代；一个念头从地面升到天界；一章内容翻页。

- **散花。** 飞天扬手，花瓣从手中散出，花瓣飘落的轨迹带出主体。
  *适合内容如：*一次祝福；一个新品发布的开场；一段祝福语的字幕载体。

- **反弹琵琶。** 飞天反手弹拨背后的琵琶，飘带随乐声起浪。
  *适合内容如：*音乐类内容；传统工艺的「巧」；一个需要展示「技艺」的瞬间。

- **凹凸晕染显现。** 面部的凹凸晕染（西域法）从平涂中逐渐浮现，立体感一层层叠上来。
  *适合内容如：*一个人物的登场；一个概念从抽象到具体；一段历史的显影。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **脸崩** | 飞天面部五官错乱、多指 | 提示词里**不写「飞天仙女」这种强文化词**，改写「侧脸的乐伎人物，闭目」；避开正面特写 |
| **飘带物理错** | 飘带像布料一样下垂、缠绕打结 | 显式写「飘带不受重力，持续向画面左侧舒展，不垂落、不打结」 |
| **退化成 3D** | 变成光滑的 3D 佛像渲染 | 负面词必须有「不要 3D 渲染质感、不要 CG 光泽、不要立体塑形」 |
| **颜色太鲜艳** | 变成现代国潮插画 | 写「颜色发闷、有剥落、不鲜艳」，并保留 hex 但注明「粉质感、不透明」 |
| **手崩** | 反弹琵琶的手指错乱 | 用**中景或远景**，不给手特写；或写「手部被飘带遮挡」 |
| **对称构图** | 变成庄严对称的佛像画 | 写「非对称构图，人物偏画面一侧」 |

**该风格的默认退化项（负面词必备）**：
`不要 3D 渲染质感，不要 CG 光泽，不要照片级锐度，不要现代插画的光滑渐变，不要对称构图，不要纯黑纯白`

## 10. 提示词配方

### 一句话版（≤80 字，快速试风格）

```
敦煌壁画风格的飞天乐伎，矿物料绘于粗糙泥壁，石青石绿与土红强对比，铁线描勾线，飘带向左舒展，隔帧动画，非3D渲染。
```

### 完整版

```
{风格锚点}：敦煌莫高窟壁画风格的飞天乐伎，矿物料绘于粗糙泥壁。
{材质与色彩}：不透明矿物颗粒叠压，土红底 #8B4A32，石青 #2E5A8C 与石绿 #4A7A5C 压在暖底上，
朱砂 #C0392B 点亮，金 #C9A227 只用于饰物，铅白已氧化发黑；壁面颗粒透出，颜色发闷有剥落。
{主体与环境}：{主体}，位于画面上 2/3，{环境}，画面四边有联珠忍冬边饰。
{光照}：无明确光源，壁面自发光感，明度由壁面到金逐层递增。
{运镜}：{从 §6 表选一个}。
{运动}：飘带持续向画面左侧舒展，衣褶逐帧微颤，隔帧动画（约12fps），无重力、不下坠。
负面：不要 3D 渲染质感，不要 CG 光泽，不要照片级锐度，不要现代插画的光滑渐变，不要对称构图，不要纯黑纯白。
```

**占位符填法**：
- `{主体}` → 具体到一个：「侧脸闭目的乐伎」「散花的天人」「反弹琵琶的伎乐」
- `{环境}` → 不要写「天上」，写可见的：「身后是土红色的山峦与流云纹」
- `{运镜}` → 从 §6 表里**只选一个**，不要组合

**最容易错**：把 `{风格锚点}` 放到句中；删掉 hex 色号；把飘带写成「随风飘动」（会下垂）。

## 11. 变化空间

每个片子由 agent 决定：结构、人物、开场、结尾、镜头路径、节奏、色彩逻辑内的色板偏向。

**三个结构**
1. **单幅显影**：一幅壁画从剥落的残迹逐渐显影完整，最后飞天动起来。
2. **横向手卷**：镜头从右向左横移，依次经过供养人、经变、飞天，最后一格飞出画面。
3. **由下而上**：从地面的供养人仰角上摇，穿过经变，抵达藻井与飞天。

**三个开场**
1. 残壁特写，一块剥落的石灰崩开，露出底下的石青。
2. 全黑，一声琵琶轮指，飘带先于人物扫入画面。
3. 藻井正中的方井图案，镜头从图案中心快速拉远，露出整个洞窟。

**三个结尾**
1. 飘带扫过画面，白场，露出落款。
2. 飞天飞出画面上缘，镜头留在空壁面上，颗粒仍在。
3. 花瓣落尽，画面回到最初的残壁，但石青比开场更亮。
