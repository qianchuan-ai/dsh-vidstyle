# 拼贴手账 — collage-journal

> 撕开的纸、和纸胶带、票据、拍立得、手写字，一层一层贴在本子上，边缘是撕的不是裁的。本风格做的是
> **「手工的层次」**——你看得出哪张纸先贴、哪张后贴，胶带压住了什么。
> 参考（只取语法）：剪贴簿的**层次叠压**与**撕边**；拍立得的**白框与日期感**；
> 手账的**手写标注与胶带固定**。不搬具体素材、品牌与内容，成片里不点名。

## 1. 本质，以及它不是什么

1. **撕边**。纸的边缘是**撕出来的毛边**，不是裁出来的直边——这是手工感的核心。
2. **层次叠压**。素材**一层压一层**，看得出**谁先谁后**，胶带压住上层的角。
3. **混合媒介**。同一画面里有**不同的材质**：纸、胶带、布、金属箔、照片、手写字。
4. **不完美**。元素**不完全对齐**，有轻微的倾斜与重叠——整齐就不是手账了。
5. **手写标注**。箭头、圈注、批注是**手写的**，不是排版的。

**不是什么**：不是平面设计（太整齐、无材质层次），不是 3D 渲染（无厚度与投影），
不是数字贴纸（太干净），不是照片拼接（照片只是其中一种素材）。

## 2. 材质与质感

**基底**：手账本的纸。可见**纸的纹理与格线/点阵**，可能有旧的胶痕。

**材质**：
- 牛皮纸 #C4A574 —— 底层，有纤维
- 白卡纸 #F5F2EA —— 上层，干净
- 和纸胶带 #E8C8A0（半透明）—— 压住边缘，**能透见下面的字**
- 拍立得白框 #F7F4EC —— 照片的白边
- 手写墨 #2B2B2B —— 手写字与箭头
- 印章红 #C0392B —— 日期章、强调- 撕边的毛 —— 纸撕开处的**纤维毛刺**

**渲染逻辑**：**一层压一层，每层有薄投影**（约 2–4 像素，方向一致）。
和纸胶带**半透明**，能透见下面的字。撕边有**纤维毛刺**。
AI 生成对应「层次叠压 + 薄投影 + 半透明胶带 + 撕边毛刺」，不要「平贴无投影」。

**必须锚在世界上的**：撕边的毛、层次的投影、胶带的半透明。**活在画面空间里的**：
整体的暖旧调与不完美对齐。

## 3. 色彩逻辑

**规则**：
- **暖旧为主**。牛皮纸、米白、浅褐构成底，**饱和度低**。
- **一两个强调色**。印章红或胶带的某个颜色做点缀，**不要多**。
- **照片自带的颜色**。拍立得里的颜色可以比周围**略鲜艳**（它是「贴上去的另一层」）。
- **不上的色**：纯黑 #000、纯白 #FFF、荧光色、高饱和的大面积色。
- **明度排序**：白卡纸（最亮）→ 牛皮纸 → 胶带 → 照片 → 手写墨（最暗，点状）。

**示例色板（仅示例）**：
`#F5F2EA 白卡纸 / #C4A574 牛皮纸 / #E8C8A0 和纸胶带 / #F7F4EC 拍立得白框 / #2B2B2B 手写墨 / #C0392B 印章红`

## 4. 字体与字幕

- **标题**：**手写体**（钢笔或马克笔的笔迹），或**打字机字体**（复古打印感）。
  字色用手写墨 #2B2B2B 或印章红 #C0392B。
- **字幕**：细手写体或细宋体，像贴上去的纸条。
- **字号**：标题占画面高度 9%–13%，字幕 4%–5%。
- **归属**：字幕像**贴上去的纸条或便签**，有轻微倾斜与投影。
- **阅读时长**：至少停留 max(1.8 秒, 语音 + 0.6 秒)。

**注意**：手写字 AI 容易写错。**文字尽量短（2–6 字）**，或写「字迹潦草不可辨，只见笔迹」，
复杂的字后期加。

## 5. 运动质感

- **抽帧感**：**不抽帧**，但**元素的出现是「贴上去」的**（有停顿感）。
- **缓动**：**落下的缓动**（元素从上方落下或从旁边滑入，落地时有轻微的回弹）。
- **重量**：纸**轻**，但有**空气感**（落下时飘一下）。
- **抖动**：**轻微的手持抖动**（像在翻本子），或完全稳定。
- **出现与消失**：**贴上去**（从画外滑入或落下，落地有回弹），不是淡入。
- **什么永不动**：本子的格线/点阵、底层的纸。

## 6. 运镜语法

| 运动 | 表达什么 | 能服务 |
|---|---|---|
| 缓慢的平移（翻本子） | 浏览、回顾、一段并列 | 一段回顾；并列的内容；清单 |
| 缓慢推近至某个素材 | 聚焦、细看、强调 | 一个重点；一次发现 |
| 缓慢拉远到整页 | 全貌、完成、看清 | 一页的完成；一个总结 |
| 锁死画框 | 陈列、展示、静止 | 让观众看整页；一段静止 |
| 轻微的倾斜漂移（手持感） | 临场、在翻、亲手 | 一段临场；一次翻阅 |

**取景规则**：素材**不居中**，压一角或分散；有**轻微倾斜**（2–5°）；
层次的投影方向**一致**（光从左上来）。**允许的转场**：新素材贴上、翻页、胶带撕开。
**禁止**：360° 环绕、快速甩镜、完全水平的整齐构图。

## 7. 声音色板

- **乐器**：尤克里里/木吉他的轻拨、钟琴、口哨——**轻快、手作感**，不要宏大的管弦。
- **拟音**：撕纸、胶带撕开与贴上、笔在纸上写、翻页、盖章的「咔」。
- **环境**：室内的安静，偶尔的桌面动静。
- **静默**：**至少一处**，只有翻页与写字声。
- **混音**：拟音突出（这是手账的灵魂），音乐给轻快的底；响度 −14 LUFS。
- **人声**：轻快，像在分享。

## 8. 招牌动作

- **贴上去。** 一张素材**从画外滑入或落下**，落地时**轻微回弹**，胶带随后压上角。
  *适合内容如：*一个内容的逐条出现；一次分享；一段清单。

- **撕开胶带。** 和纸胶带**被撕开**，露出下面被压住的字。
  *适合内容如：*一次揭示；一个遮挡被移除；一次「拆开」。

- **翻页。** 页面**被翻过去**，下一页的内容显露，翻页时有纸的弯曲。
  *适合内容如：*一次转场；一段内容的推进；章节的切换。

- **盖章。** 日期章或强调章**盖下去**，有轻微的墨迹不均。
  *适合内容如：*一次确认；一个日期；一个重点的标记。

## 9. AI 生成避坑

| 坑 | 现象 | 修法 |
|---|---|---|
| **手写字错乱** | 字迹变形、笔画错 | **文字控制在 2–6 字**；或写「字迹潦草不可辨，只见笔迹」；复杂的字后期加 |
| **太整齐** | 元素完美对齐，像平面设计 | 「元素有 2–5° 倾斜，不完全对齐，有重叠，手工感」 |
| **没有投影** | 元素平贴，无层次 | 「每层有 2–4 像素薄投影，方向一致（光从左上）」 |
| **撕边变直边** | 边缘是裁的 | 「撕开的毛边，有纤维毛刺，非裁切直边」 |
| **退化成 3D** | 变成 3D 渲染的纸 | 负面词必须有「不要 3D 渲染质感、不要立体塑形」 |
| **胶带不透明** | 胶带盖住了下面的字 | 「和纸胶带半透明，能透见下面的字与笔迹」 |

**该风格的默认退化项（负面词必备）**：
`不要 3D 渲染质感，不要平面设计的整齐对齐，不要裁切直边，不要纯黑纯白，不要荧光色，不要无投影的平贴`

## 10. 提示词配方

### 一句话版

```
手账拼贴风，撕边纸张层次叠压带薄投影，和纸胶带半透明压角，拍立得白框，手写标注与印章，轻微倾斜不整齐。
```

### 完整版

```
{风格锚点}：手账拼贴风，混合媒介贴在本子上。
{材质与色彩}：撕开的毛边（有纤维毛刺，非裁切直边）；层次叠压，每层有 2–4 像素薄投影
（方向一致，光从左上）；和纸胶带 #E8C8A0 半透明（能透见下面的字）；牛皮纸 #C4A574 底、
白卡纸 #F5F2EA 上层、拍立得白框 #F7F4EC；手写墨 #2B2B2B、印章红 #C0392B 点缀；
元素有 2–5° 倾斜，不完全对齐，有重叠。
{主体与环境}：{主体}，{环境}，本子的格线/点阵在底层可见。
{光照}：均匀的室内光，投影薄而一致，无强烈明暗。
{运镜}：{从 §6 表选一个}。
{运动}：{主体动作}，素材贴上时从画外滑入或落下（落地轻微回弹），纸有空气感，
轻微手持抖动或稳定。
负面：不要 3D 渲染质感，不要平面设计的整齐对齐，不要裁切直边，不要纯黑纯白，不要荧光色，不要无投影的平贴。
```

**占位符填法**：
- `{主体}` → 「一张拍立得」「一段手写便签」「一枚邮票与票据」
- `{环境}` → 「牛皮纸底上有格线」「旁边压着和纸胶带」
- `{运镜}` → 缓慢平移（翻本子）最适合展示内容

**最容易错**：写太多字（会错乱）；太整齐；没有投影；撕边变直边。

## 11. 变化空间

**三个结构**
1. **逐条贴上**：素材一条一条贴上来，最后是一页完整的手账。
2. **翻页回顾**：镜头翻过三页，每页一个主题，同一风格。
3. **由零到整**：从空白页开始，一层层加，最后满页。

**三个开场**
1. 全是空白格线纸，第一张素材落下。
2. 撕纸的极特写，毛边出现。
3. 一支笔在纸上写，字迹出现。

**三个结尾**
1. 最后一枚印章盖上，画面静止。
2. 镜头拉远，一页缩成本子的一角，手合上本子。
3. 翻过最后一页，空白页，笔放在旁边。
