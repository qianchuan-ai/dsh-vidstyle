# 平台语法对照

同一段风格配方，在不同平台要换算画幅、时长和语法。本页是对照表；具体风格的配方在
`styles/<slug>/STYLE.md` §10。

> ⚠️ 各平台的提示词规范、时长上限、画幅选项会随版本更新。本页写的是**结构性差异**
> （语序习惯、负面词支持、图生视频行为），这些相对稳定；具体数值用前请以平台当前文档为准。

## 1. 结构性差异速查

| | 即梦 AI | Seedance | 可灵 AI | 通义万相 |
|---|---|---|---|---|
| **出品** | 字节跳动 | 字节跳动 | 快手 | 阿里巴巴 |
| **接入** | 抖音系 App / 网页 | 即梦内 / API | 快手系 App / 网页 | 阿里云 / 网页 |
| **主要语法** | 中文自然段 | 中文结构化，分镜友好 | 中文自然段 | 中英皆可 |
| **风格锚点位置** | 开头最有效 | 开头最有效 | 开头最有效 | 开头最有效 |

## 2. 画幅换算

配方里写的构图比例是按 **16:9** 给的基准。换画幅时，**只改构图描述，不改风格锚点**：

| 目标画幅 | 构图改法 |
|---|---|
| **9:16 竖屏** | 「主体居中偏上，下方留 1/4 空白给字幕；背景纵向延伸」 |
| **3:4** | 「主体占画面上 2/3，下 1/3 留白；构图偏静物/封面」 |
| **1:1** | 「主体正中，四周留白均匀；去掉横向延伸的环境描述」 |
| **16:9** | 基准，不改 |

**竖屏是中式短视频的默认**，所以本库所有配方默认按 9:16 写，横屏需求再反向换算。

## 3. 时长与镜头数

| 平台 | 单镜头建议 | 一条片建议 |
|---|---|---|
| 即梦 | 3–5 秒 | 15–60 秒（多镜头拼接） |
| Seedance | 4–8 秒 | 支持较长的连续叙事 |
| 可灵 | 3–5 秒 | 5–10 秒单段 |
| 万相 | 3–6 秒 | 按模板 |

**超过 6 秒的单镜头**，在配方末尾加一句：
`全程锁定当前风格，不发生风格切换、不出现新主体`

## 4. 语法写法差异

### 即梦 / 可灵 —— 自然段式

一段连贯中文，风格锚点在最前，负面词独立成句：

```
{风格锚点}。{材质与色彩}。{主体与环境}。{光照}。{运镜}。{运动}。
不要{该风格 §9 的退化项}。
```

### Seedance —— 结构化分镜式

适合多镜头。每个镜头一段，段首标镜头号，段内再分运镜 / 运动：

```
镜头1｜{景别}：{运镜}。{主体与环境}。{运动}。
镜头2｜{景别}：{运镜}。{主体与环境}。{运动}。
风格：{风格锚点}，{材质与色彩}，全程保持。
负面：{该风格 §9 的退化项}。
```

### 万相 —— 中英混排更稳

风格锚点用中文（语料更准），技术参数用英文（模型对英文数值更敏感）：

```
{中文风格锚点}，{中文材质与色彩}。
Camera: {push in / lateral track / locked frame}, {lens}。
Motion: {主体运动}，{抽帧感描述}。
Negative: {英文负面词}。
```

## 5. 图生视频的换算

用首帧图片驱动视频时，配方按 `TECHNIQUE.md` §7 改写：

| 段落 | 图生视频时 |
|---|---|
| 风格锚点 | **删**（首帧已携带） |
| 材质与色彩 | **删** |
| 主体与环境 | **删**（首帧已定） |
| 光照 | 保留，但改成「维持首帧光照」 |
| 运镜 | **保留**，这是新增信息 |
| 运动 | **保留**，这是新增信息 |
| 负面词 | **保留**，并加「不要风格漂移」 |
| — | 追加：`保持首帧的{风格名}质感与色调，全程不切换风格` |

**首帧图片**本身则用**完整配方**生成（图片模型对风格锚点响应比视频模型强）。

---

## 6. 负面词的平台接受度

| 平台 | 负面词写法 |
|---|---|
| 即梦 | 句末单独一句「不要…」，多项用顿号 |
| Seedance | 单独一行 `负面：…`，最吃这套 |
| 可灵 | 自然段内即可，效果中等 |
| 万相 | `Negative: …` 英文列举，逗号分隔 |

**共同禁忌**：不要写「避免 XXX 风格」这种抽象负面词，要写具体的质感退化项
（「不要 3D 渲染质感」「不要照片级锐度」「不要镜头光晕」）。

---

## 7. 本库配方的默认假设

除非用户指定，`STYLE.md` §10 的配方默认：

- **画幅** 9:16（1080×1920）
- **单镜头** 4 秒
- **平台** 即梦（自然段式，中文，负面词句末）
- **风格锚点** 置于句首
- **hex 色号** 保留不删

换平台时按 §4 改写法，换画幅时按 §2 改构图，**风格锚点和材质色彩两段永远不动**。
