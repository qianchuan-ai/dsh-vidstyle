# 技法：这些提示词是怎么写出来的

本库的每一份 `STYLE.md` 都是给**文生视频 / 图生视频**用的，不是给代码渲染用的。这一页解释
写法本身——配一份 `styles/<slug>/STYLE.md` 和 `LIB/PLATFORMS.md`（平台语法对照）使用。

```
题材
 ├─► 选风格 ──► 读该风格 STYLE.md §1–§9（语法）
 ├─► 填配方 ──► §10 的骨架，替换占位符
 ├─► 定镜头 ──► §6 的运镜词汇 + §8 的招牌动作
 ├─► 出负面 ──► §9 的避坑（每条都有对应修法）
 └─► 适配平台 ──► PLATFORMS.md 换算画幅、时长、语法
 → 一段可直接粘贴的提示词
```

---

## 1. 三条底层原则

**一、材质优先于形容词。**
「很有水墨感」不是提示词，是评价。「生宣上洇开的湿墨，边缘有纤维毛刺」才是。模型不认识
「感」，它认识材质。每一个风格词都要能落到一个**看得见的物理事实**上。

**二、数字是约束，不是装饰。**
「深黑占画面 25%–35%」「轮廓线约画面宽的 1/400」「24 fps 抽帧感」——这些数字给模型一个
可执行的边界，比「对比强烈」「线条细腻」稳定得多。本库所有 hex 色值同理：写具体色号，
不要写「天青色」。

**三、中文提示词的语序有权重。**
主流中文视频模型对**开头的风格锚点**响应最强，对**句末的负面词**次之，对中段的细节最弱。
所以本库的配方一律是：

> **风格锚点 → 材质与色彩 → 主体与环境 → 光照 → 运镜 → 运动 → 负面**

不要把风格词藏在中间。先说「这是一幅工笔绢本设色」，再说画的是什么。

---

## 2. 风格锚点怎么写

风格锚点是提示词的第一个短语，作用是把模型拉进正确的流形。三种写法，按强度递增：

| 写法 | 例子 | 什么时候用 |
|---|---|---|
| **媒介 + 传统** | 工笔绢本设色，三矾九染 | 最稳，模型见过大量此类语料 |
| **媒介 + 年代/流派** | 1930 年代正色片拷贝，琥珀染色 | 需要特定历史质感时 |
| **媒介 + 反例** | 手绘二维动画，非 3D 渲染 | 模型容易退化成默认写实时 |

**反例尤其重要。** 当一个风格和模型的「默认审美」冲突时（比如水墨 vs 写实、皮影 vs 3D），
必须显式写出不要什么。见 §4 负面词。

---

## 3. 占位符怎么填

`STYLE.md` §10 的配方里，占位符分六类，每类有自己的填法：

| 占位符 | 填什么 | 最容易错在哪 |
|---|---|---|
| `{主体}` | 一个具体的、可辨识的东西 | 填成一类东西（「一只鸟」→「一只立在枯枝上的灰喜鹊」） |
| `{环境}` | 主体所在的空间 + 时间 + 天气 | 填成氛围词（「很美」→「薄雾里的江南水乡石桥，清晨」） |
| `{材质色彩}` | 该风格 §2 §3 的规则，带 hex | 照抄色板而不按题材调整 |
| `{光照}` | 光的方向、硬度、色温 | 只写「光线柔和」 |
| `{运镜}` | §6 表里选一个运动 | 每个镜头都想动 |
| `{运动}` | 主体自己的动作 + 抽帧感 | 把运镜和主体运动混为一谈 |

**`{主体}` 是唯一必须由题材决定的**，其余五类都从 `STYLE.md` 里取。这就是「风格可复用、
主体每次换」的机制。

---

## 4. 负面词的中式写法

负面词是中文提示词里最容易写错的一环。三条规则：

**一、写「不要什么质感」，不要写「不要什么风格」。**
「不要摄影感」模型不知道怎么执行。「不要照片级锐度、不要景深虚化、不要镜头光晕」可以。

**二、负面词要和风格锚点配对。**
每个风格的 §9 都列了它**最容易退化成的默认输出**。水墨的默认退化是「3D 渲染的假山石」，
所以负面词里必须有「不要 3D 渲染质感、不要 CG 光泽」。这些是该风格专属的，不是通用模板。

**三、负面词放在句末，单独一句。**
不要混在描述里。混在一起模型会把负面词当正面描述的一部分。

---

## 5. 运动与运镜分两层写

这是视频提示词区别于图片提示词的核心。**两层必须分开写，不能合并成一句：**

- **运镜（camera）**：镜头怎么动 —— 推、拉、摇、移、跟、升降、环绕、锁死
- **运动（motion）**：画面里的东西怎么动 —— 主体动作、材质变化、抽帧感、粒子

合并写（「镜头缓缓推近，飞天的飘带向左飘动」）在多数平台上会退化成只执行一个。
正确写法是两个分句，用分号或换行隔开：

> 运镜：镜头从远景缓慢推近至中景。
> 运动：飞天的飘带持续向画面左侧舒展，衣褶逐帧微颤，抽帧感（隔帧动画）。

## 6. 时长与画幅的取舍

| 画幅 | 用途 | 时长建议 |
|---|---|---|
| 9:16（1080×1920） | 抖音、视频号、小红书竖屏 | 单镜头 3–5 秒，一条 15–60 秒 |
| 3:4（1080×1440） | 小红书图文封面、封面图 | 静帧优先，动效 2–3 秒 |
| 16:9（1920×1080） | B 站、YouTube、横屏短片 | 单镜头 4–8 秒 |
| 1:1（1080×1080） | 朋友圈、商品主图 | 2–4 秒 |

**单镜头越长，风格越容易崩。** 超过 6 秒的单镜头，建议在配方里加一句「中途锁定风格，不切换」，
或者拆成两个镜头用招牌动作衔接（§8）。

---

## 7. 图生视频的额外一层

用图生视频（首帧 → 视频）时，**首帧已经携带了大部分风格信息**，提示词的作用从「建立风格」
变成「维持风格 + 指定运动」。这时配方要改：

1. **删掉风格锚点和材质色彩段**（首帧已经有了，重复写反而会漂）
2. **保留运镜、运动、负面词**
3. **加一句风格锁定**：`保持首帧的水墨质感与色调，全程不切换风格`

首帧图片的提示词则用**完整配方**（图片模型对风格锚点的响应比视频模型强）。

---

## 8. 一次生成不满意的排查顺序

按这个顺序查，不要同时改多个变量：

1. **风格没进去** → 风格锚点是不是被放在了句中？提到最前面。
2. **风格进去了但主体不对** → `{主体}` 是不是太抽象？加一个具体细节。
3. **颜色不对** → `{材质色彩}` 里的 hex 有没有被删掉？中文提示词里色号是强约束。
4. **动得不对** → 运镜和运动是不是被合并了？拆成两个分句。
5. **崩成 3D/写实** → 负面词是不是缺了该风格 §9 的专属条目？
6. **整体还行但没那个味道** → 加 §8 的**招牌动作**，它是这个风格独有的、模型学不来的瞬间。

---

## 9. 本库不做什么

- **不生成图片或视频**，只产出提示词。生成交给即梦 / Seedance / 可灵 / 万相。
- **不保证一次过**。提示词是提高命中率，不是确定性输出；§8 的排查顺序就是为此存在。
- **不替代分镜**。本库管「一个镜头长什么样」，不管「一整支片子怎么讲故事」——那是
  `LIB/DIRECTOR.md` 的事。
